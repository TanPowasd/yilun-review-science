# 高三理科一轮复习笔记

数学 · 物理 · 化学 · 生物（苏州 · 江苏新高考，选科物化生）。按学习顺序逐章整理。

## 用 Obsidian 打开

本仓库就是一个 Obsidian 库：「打开文件夹作为库」选仓库根目录，从 [[首页]] 开始。笔记带属性（frontmatter：标签、别名、科目、序号、日期），内部链接是 `[[双链]]`，图片用 `![[嵌入]]`，「怎么想到的」「易错提醒」是 callout。公式（LaTeX）和 Mermaid 流程图 Obsidian 原生支持。GitHub 网页上双链显示为原文，属正常。

## 目录结构

```
<学科>/
  notes/       每章一个 md 笔记（知识点、公式、易错、例题）
  images/      图片（Vmotion 制作，必要时才做）
  flowcharts/  流程图（Mermaid 源码 .mmd + 导出图）
  tables/      表格（考点表、公式表 .md / .csv）
  videos/      讲解视频（Vmotion 工程 + 导出 MP4，必要时才做）
```

学科：`math/` 数学 · `physics/` 物理 · `chemistry/` 化学 · `biology/` 生物
