# 动量能量七大模型 · Vmotion 工程

约 100 秒动画（1920×1080，30fps），用 Vmotion 打开本文件夹即可编辑/导出。

| 时间 | 内容 |
|---|---|
| 0:00 | 片头：七大模型 + "动量管速度，能量管位移、高度、热量" |
| 0:06 | ① 弹性 vs 完全非弹性碰撞（A 1kg 6m/s 撞静止 B 2kg） |
| 0:18 | ② 板块（v–t 图阴影面积 = 相对位移；共速定格） |
| 0:30 | ③ 弹簧（最短共速定格，Ep 最大 3 J） |
| 0:44 | ④ 可动光滑圆弧槽（RK4 数值积分；最高点共速定格） |
| 0:56 | ⑤ 子弹打木块（慢放 25 倍；Q = f·d） |
| 1:10 | ⑥ 人船（x人 = 3 m，x船 = 1 m） |
| 1:22 | ⑦ 爆炸与反冲（动能 0 → 12 J） |
| 1:32 | 片尾口诀 |

- `components/models.ts`：全部动画逻辑（参数 `model` 切换模型），运动均为解析解/确定性积分，可任意帧跳转。
- `scenes/*.json`：每个模型一个场景；`sequences/main.json`：按顺序拼接，含章节标记。
- 导出：`vmotion render --project . --output exports/models.mp4`。MP4 成品较大，未放入仓库。
