# 演示图统一模板（讲义风）

2026-10-16 起所有静态演示图都用这一套，参考实现：`02-模型拓展/components/variants.ts`。

- 画布 1920×1080，米白纸底 `#f6f3ec`；内容放在白色卡片里（细灰边 `#ddd7ca`，圆角 4）。
- 页眉：灰色小字「物理 · 章节 · 专题　k / n」→ 深蓝标题 `#1f3a5f` → 灰色副标题 → 深蓝细横线。
- 卡片：标题深蓝 27px + 下方细灰分隔线；顺序固定：题干（灰）→ 示意图 → 方程。
- 物体：浅色底 + 同色描边（蓝 `#2f6db5` / 褐 `#b8642c` / 紫 `#7b5aa6`），小球实心蓝。地面一律画斜线阴影，必要时注明「光滑 / 粗糙」。
- 颜色只用于区分物体和标注：红 `#c0392b` 只给「注意」，绿 `#2e8b57` 只给能量/上升量。
- 方程：左侧短标签（动量 / 能量 / 代入 / 结果 / 注意），先字母式，下一行「代入」。
- 公式里不要写中文（`\text{中文}` 会渲染成空白），中文放普通文字行；下标数字用普通字符 m1、v0。
- 措辞平实，用教辅书的说法，不用「新面孔」「换了皮」这类口语。
