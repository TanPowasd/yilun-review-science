## 0. 先补基础：6 个前置概念

| 概念 | 公式 | 大白话 | 字母含义 |
|---|---|---|---|
| 电场力 | F = qE | 电荷在电场里被推 | q 电荷量（C），E 场强（V/m 或 N/C） |
| 匀强电场 | E = U/d | 两块平行板之间电场处处一样 | U 两板电压（V），d 板间距（m） |
| 电场力做功 | W = qU | 电荷穿过电压 U，能量变化 qU | — |
| 洛伦兹力 | f = qvB（v⊥B） | 运动电荷在磁场里被"侧推" | v 速度，B 磁感应强度（T） |
| 安培力 | F = BIL（I⊥B） | 通电导线在磁场里受力 | I 电流（A），L 导线在磁场中的长度 |
| 法拉第定律 | E = nΔΦ/Δt；切割时 E = BLv | 磁通量变得越快，感应电动势越大 | Φ = BS 磁通量（Wb），n 匝数 |

**三个方向定则**（只记用途，别混）：
- **左手定则**：判断**力**的方向（洛伦兹力、安培力）。"左力"。
- **右手定则**：判断导体棒**切割**产生的电流方向。
- **楞次定律**：感应电流的效果总是**阻碍**原来的变化——导体棒运动时，安培力一定**阻碍运动**（这条最好用）。

**最重要的一句**：洛伦兹力**永远和速度垂直，永远不做功**——粒子在纯磁场中速度大小不变，只改方向。

## A1. 电场中：加速和偏转

![带电粒子](../images/05-电磁综合/05-1-带电粒子.png)

### 1. 加速（初速为零，穿过电压 U₁）
- 字母式：`qU₁ = ½mv₀²` ⇒ `v₀ = √(2qU₁/m)`
- 为什么用动能定理：电场力做功 qU₁ 全部变成动能，不用管中间怎么加速。

### 2. 偏转（垂直电场射入平行板，板长 L、间距 d、电压 U₂）
就是"类平抛"：水平方向匀速，竖直方向匀加速。
- 竖直加速度：`a = qE/m = qU₂/(md)`
- 在板间的时间：`t = L/v₀`
- 侧移：`y = ½at² = qU₂L²/(2mdv₀²)`
- 偏转角：`tanθ = v_y/v₀ = at/v₀ = qU₂L/(mdv₀²)`
- **先加速后偏转**，把 v₀² = 2qU₁/m 代入：`y = U₂L²/(4U₁d)`，`tanθ = U₂L/(2U₁d)`
  - 结论：**和粒子的 q、m 无关**——不同粒子经同一电场加速、再同一电场偏转，轨迹完全一样。
- 出射时速度的反向延长线过**板长的中点**（选择题常用）。

### 例 1（配图 1 左）
> 比荷 q/m = 1×10⁸ C/kg 的粒子从静止经 U₁ = 200 V 加速，垂直射入板长 L = 0.1 m、间距 d = 0.05 m、电压 U₂ = 80 V 的平行板。求 v₀、侧移 y、偏转角正切，能否射出？

1. 加速：`v₀ = √(2qU₁/m)`，代入 `v₀ = √(2×10⁸×200) = √(4×10¹⁰) = 2×10⁵ m/s`
2. 侧移：`y = U₂L²/(4U₁d)`，代入 `y = 80×0.01/(4×200×0.05) = 0.8/40 = 0.02 m`
3. 能否射出：粒子从两板正中射入，最多能偏 d/2 = 0.025 m；0.02 m < 0.025 m ⇒ **能射出**
4. 偏转角：`tanθ = U₂L/(2U₁d)`，代入 `tanθ = 80×0.1/(2×200×0.05) = 8/20 = 0.4`

## A2. 磁场中：匀速圆周运动

### 1. 两个基本公式
- 洛伦兹力提供向心力：`qvB = mv²/r`
- ⇒ 半径 `r = mv/(qB)`（速度越快，圆越大）
- ⇒ 周期 `T = 2πr/v = 2πm/(qB)`（**和速度无关**）
- 在磁场里转过圆心角 θ，用时 `t = θ/(2π) · T`（θ 用弧度；用角度时 `t = θ/360° · T`）

### 2. 三步走：找圆心 → 定半径 → 算时间
1. **找圆心**：圆心在"速度的垂线"上。知道两个点的速度方向，两条垂线的交点就是圆心；只知道一个速度方向和另一点位置，用"速度垂线 + 弦的中垂线"的交点。
2. **定半径**：用几何（勾股定理、三角函数）列出 r，再和 r = mv/(qB) 联立。
3. **算时间**：先求圆心角 θ。**圆心角 = 速度偏转角**（粒子速度转了多少度，圆心角就是多少度）。

### 3. 有界磁场的常用结论
- 直线边界：射入和射出时，速度与边界的夹角**相等**（对称）。
- 圆形磁场：沿半径方向射入，必沿半径方向射出。
- 宽度为 d 的条形磁场，垂直边界射入：`sinθ = d/r`（θ 为偏转角）；若 r ≤ d 则从入射边界转回去。

### 例 2（配图 1 右）
> 例 1 中的粒子（v = 2×10⁵ m/s，q/m = 1×10⁸ C/kg）垂直边界射入宽 d = 0.01 m、B = 0.1 T 的匀强磁场。求半径、偏转角和在磁场中的时间。

1. 半径：`r = mv/(qB) = v/((q/m)B)`，代入 `r = 2×10⁵/(10⁸×0.1) = 0.02 m`
2. 偏转角：r = 0.02 m > d，会从另一边射出。`sinθ = d/r`，代入 `sinθ = 0.01/0.02 = 0.5` ⇒ `θ = 30°`
3. 周期：`T = 2πm/(qB)`，代入 `T = 2π/(10⁸×0.1) = 2π×10⁻⁷ s`
4. 时间：`t = θ/360° · T`，代入 `t = 30/360 × 2π×10⁻⁷ = (π/6)×10⁻⁷ s ≈ 5.2×10⁻⁸ s`

## A3. 组合场：先电场，后磁场

做法：**分段处理**。交界处的速度（大小和方向）是两段的"接力棒"。

### 1. 质谱仪
- 先加速：`qU = ½mv²`
- 再进磁场做半圆：`r = mv/(qB)`
- 联立：`r = (1/B)√(2mU/q)`，打在底片上的位置 `x = 2r`
- 用途：r 只和比荷有关，比荷不同的粒子落点不同 ⇒ 分离同位素。

### 2. 回旋加速器
- 每过一次缝隙加速一次（电压 U），在 D 形盒里转半圈。
- 交变电压周期 = 粒子周期：`T = 2πm/(qB)`
- 最大动能由 D 形盒半径 R 决定：`v_max = qBR/m`，`E_k,max = q²B²R²/(2m)`——**和加速电压 U 无关**（U 只影响加速几圈）。
- 加速次数：`n = E_k,max/(qU)`

## A4. 叠加场：几个场在同一地方

### 1. 速度选择器（E 和 B 垂直）
- 粒子不偏转（直线通过）：电场力 = 洛伦兹力，`qE = qvB` ⇒ `v = E/B`
- 和电荷正负、q、m 都无关，只"选"速度。
- 例：E = 2×10⁴ V/m，B = 0.1 T ⇒ v = 2×10⁴/0.1 = 2×10⁵ m/s（恰好就是例 1 的粒子速度）。
- v > E/B：洛伦兹力大，往洛伦兹力那边偏；v < E/B：往电场力那边偏。

### 2. 重力 + 电场 + 磁场（带电小球）
- **匀速圆周运动**：说明重力被电场力平衡，`qE = mg`，只剩洛伦兹力，`r = mv/(qB)`
- **匀速直线运动**：三力合力为零（洛伦兹力会随速度变，所以有洛伦兹力参与的直线运动一定是匀速）
- 其他曲线：洛伦兹力不做功，用**动能定理**只算重力和电场力做功。

## B1. 电磁感应的"三件套"

导体棒（长 L，电阻 r）在磁场 B 中以速度 v 切割，接外电阻 R：

1. 电动势：`E = BLv`
2. 电流：`I = E/(R + r) = BLv/(R + r)`（记 R总 = R + r）
3. 安培力：`F安 = BIL = B²L²v/R总`，方向**阻碍运动**

**一句话**：速度越大，安培力越大——所以导体棒会走向一个"收尾速度"。

### 两个常用"总量"公式（不用管过程）
- **电荷量**：`q = ΔΦ/R总`；单棒切割走了 x：`q = BLx/R总`
- **动量定理**（安培力的冲量）：`−BLq = mv末 − mv初`（只有安培力时）
  - 为什么：∑BIL·Δt = BL·∑IΔt = BLq
- **焦耳热**：用能量守恒，`Q = 外力做功 − 动能增加`；R 上分到 `Q_R = Q·R/(R + r)`

这三个公式是电磁感应计算题的核心：**求距离、电荷量 → 动量定理；求热 → 能量守恒；求最大速度 → 受力平衡。**

## B2. 单棒模型（配图 2）

![单棒模型](../images/05-电磁综合/05-2-单棒模型.png)

### 1. 恒力 F 拉，光滑导轨，从静止开始
- 加速度：`a = (F − B²L²v/R总)/m`，v 增大 ⇒ a 减小
- 收尾：a = 0 时匀速，`F = B²L²v_m/R总` ⇒ `v_m = FR总/(B²L²)`
- v–t 图：斜率越来越小的曲线，最后变成水平线

### 2. 给初速度 v₀，无外力
- 安培力使棒减速，越慢减速越慢，最终停下
- 动量定理：`BLq = mv₀`；又 `q = BLx/R总` ⇒ 滑行距离 `x = mv₀R总/(B²L²)`
- 热：`Q = ½mv₀²`（动能全变热）

### 例 3
> 光滑导轨间距 L = 0.5 m，B = 1 T，回路总电阻 R总 = 1 Ω，导体棒 m = 0.1 kg。
> (1) 用恒力 F = 0.5 N 从静止拉，求最大速度；(2) 撤去拉力，若棒以 v₀ = 4 m/s 滑行，求滑行距离、通过的电荷量和产生的热。

(1) 收尾：`v_m = FR总/(B²L²)`，代入 `v_m = 0.5×1/(1²×0.5²) = 0.5/0.25 = 2 m/s`

(2)
- 动量定理：`BLq = mv₀`，代入 `1×0.5×q = 0.1×4` ⇒ `q = 0.8 C`
- 距离：`q = BLx/R总` ⇒ `x = qR总/(BL)`，代入 `x = 0.8×1/(1×0.5) = 1.6 m`
- 热：`Q = ½mv₀²`，代入 `Q = ½×0.1×4² = 0.8 J`

（数值已用逐步仿真核对：v_m → 2.000 m/s，x → 1.600 m，q → 0.800 C，Q → 0.800 J。）

## B3. 双棒模型（配图 3）

![双棒与线框](../images/05-电磁综合/05-3-双棒与线框.png)

光滑等宽导轨上两根棒，棒 1 有初速度 v₀，棒 2 静止。
- 两棒受的安培力**等大反向**（同一电流、同样 L）⇒ 系统**动量守恒**（和 01 的完全非弹性碰撞一模一样！）
- 电动势：`E = BL(v₁ − v₂)`，速度差越小电流越小，最后共速、电流为 0
- 共速：`m₁v₀ = (m₁ + m₂)v`
- 热：`Q = ½m₁v₀² − ½(m₁ + m₂)v²`
- 电荷量（对棒 2 用动量定理）：`BLq = m₂v`
- 两棒最终的距离变化：`Δx = qR总/(BL)`

### 例 4
> 光滑导轨 L = 0.5 m，B = 1 T，两棒质量都是 0.1 kg，回路总电阻 1 Ω。棒 1 以 v₀ = 4 m/s 运动，棒 2 静止。求共同速度、产生的热、通过的电荷量、两棒间距增加多少。

1. 动量守恒：`m₁v₀ = (m₁ + m₂)v`，代入 `0.1×4 = 0.2v` ⇒ `v = 2 m/s`
2. 热：`Q = ½m₁v₀² − ½(m₁ + m₂)v²`，代入 `Q = 0.8 − 0.4 = 0.4 J`
3. 电荷量：`BLq = m₂v`，代入 `0.5q = 0.1×2` ⇒ `q = 0.4 C`
4. 间距变化：`Δx = qR总/(BL)`，代入 `Δx = 0.4×1/0.5 = 0.8 m`（两棒距离缩短 0.8 m）

（已仿真核对：v → 2 m/s，Q → 0.400 J，q → 0.400 C，Δx → 0.800 m。）

> 注意：若两段导轨**宽度不同**（L₁ ≠ L₂），两棒安培力不再相等，**动量不守恒**；最终状态是"两棒电动势相等"：BL₁v₁ = BL₂v₂，再对每根棒分别用动量定理。

## B4. 线框穿过磁场

正方形线框（边长 L、质量 m、电阻 R）竖直下落，穿过宽度为 H 的水平磁场：
- 进入时下边切割，离开时上边切割；**完全在磁场里**（H > L 时）磁通量不变、没有电流，只受重力做加速度 g 的运动。
- 刚好匀速进入：`mg = B²L²v/R` ⇒ `v = mgR/(B²L²)`
- 产热：能量守恒 `Q = mg·(下落高度) − ΔE_k`

### 例 5
> 线框 m = 0.1 kg、L = 0.5 m、R = 1 Ω，B = 1 T，磁场宽度也是 0.5 m。线框从下边离磁场上边界 h 处静止下落，恰好匀速进入。求 h 和穿过磁场的总热量。

1. 匀速条件：`v = mgR/(B²L²)`，代入 `v = 0.1×10×1/(1×0.25) = 4 m/s`
2. 下落高度：`h = v²/(2g)`，代入 `h = 16/20 = 0.8 m`
3. 磁场宽度 = 边长：下边刚出磁场时上边刚进磁场，线框始终有一条边在切割，速度不变，一直匀速
4. 热：匀速，动能不变，`Q = mg·2L`，代入 `Q = 0.1×10×1 = 1 J`

## 解题步骤

![解题流程](../flowcharts/05-电磁综合-解题流程.png)

**带电粒子题**
1. 看场：只有电场？只有磁场？分区（组合场）？重叠（叠加场）？
2. 电场段：直线加速用动能定理；垂直射入用类平抛。
3. 磁场段：找圆心 → 用几何求 r → 和 r = mv/(qB) 联立 → 圆心角 = 偏转角 → t。
4. 交界处：速度大小和方向接力。
5. 叠加场：先看能否受力平衡（直线）或 qE = mg（匀速圆周）。

**电磁感应题**
1. 画电路：谁是电源（切割的棒），内阻、外阻多少。
2. 写三件套：E = BLv → I = E/R总 → F安 = B²L²v/R总。
3. 问什么用什么：最大速度 → 受力平衡；距离、电荷量 → 动量定理 + q = BLx/R总；热 → 能量守恒。
4. 双棒先看导轨宽度是否相同、是否有外力，再决定动量守不守恒。

## 易错清单

| 易错 | 正确做法 |
|---|---|
| 以为洛伦兹力做功、改变速度大小 | 洛伦兹力永远垂直速度，不做功 |
| 圆心角和偏转角分开找 | 圆心角 = 速度偏转角 |
| 回旋加速器认为电压越大最终动能越大 | E_k,max = q²B²R²/(2m)，与 U 无关 |
| 负电荷用左手定则不反过来 | 四指指向正电荷运动方向；负电荷四指指向运动反方向 |
| 电流用 E/R，忘了导体棒内阻 | I = E/(R + r) |
| 求热用 Q = I²Rt（电流在变） | 电流变化时用能量守恒 |
| 双棒不等宽也用动量守恒 | 不等宽安培力不相等，动量不守恒 |
| 求 R 上的热用总热 | Q_R = Q·R/(R + r) |

## 自测题

1. 一粒子经 U₁ = 100 V 加速后垂直射入偏转电场，板长 L = 0.08 m、间距 d = 0.04 m、U₂ = 50 V。求侧移 y 和 tanθ（不需要比荷）。
2. 比荷 q/m = 2×10⁸ C/kg、速度 4×10⁵ m/s 的粒子垂直射入 B = 0.2 T 的磁场，求半径和周期。
3. 速度选择器 E = 3×10⁴ V/m，B = 0.15 T，能直线通过的速度多大？若粒子速度更大，往哪个力那边偏？
4. 光滑导轨 L = 1 m，B = 0.5 T，R总 = 2 Ω，棒 m = 0.2 kg，恒力 F = 0.25 N 拉动，最大速度多大？
5. 第 4 题中棒达到最大速度后撤去 F，棒还能滑多远？通过的电荷量多大？
6. 双棒（等宽光滑）：棒 1 质量 0.2 kg、v₀ = 3 m/s，棒 2 质量 0.1 kg 静止。求共速和产热。

### 答案
1. `y = U₂L²/(4U₁d)`，代入 `y = 50×0.0064/(4×100×0.04) = 0.32/16 = 0.02 m`；`tanθ = U₂L/(2U₁d)`，代入 `tanθ = 50×0.08/(2×100×0.04) = 4/8 = 0.5`
2. `r = v/((q/m)B)`，代入 `r = 4×10⁵/(2×10⁸×0.2) = 0.01 m`；`T = 2π/((q/m)B)`，代入 `T = 2π/(4×10⁷) = (π/2)×10⁻⁷ s ≈ 1.57×10⁻⁷ s`
3. `v = E/B`，代入 `v = 3×10⁴/0.15 = 2×10⁵ m/s`；速度更大时洛伦兹力 qvB > qE，往洛伦兹力那边偏
4. `v_m = FR总/(B²L²)`，代入 `v_m = 0.25×2/(0.25×1) = 2 m/s`
5. 动量定理 `BLq = mv_m`，代入 `0.5×1×q = 0.2×2` ⇒ `q = 0.8 C`；`x = qR总/(BL)`，代入 `x = 0.8×2/(0.5×1) = 3.2 m`
6. `m₁v₀ = (m₁ + m₂)v`，代入 `0.2×3 = 0.3v` ⇒ `v = 2 m/s`；`Q = ½×0.2×9 − ½×0.3×4 = 0.9 − 0.6 = 0.3 J`

## 一页纸背诵版

- 电场加速：qU = ½mv²；偏转：y = U₂L²/(4U₁d)，tanθ = U₂L/(2U₁d)
- 磁场圆周：r = mv/(qB)，T = 2πm/(qB)；圆心角 = 偏转角；t = θ/360°·T
- 质谱仪：r = (1/B)√(2mU/q)；回旋加速器：E_k,max = q²B²R²/(2m)，与 U 无关
- 速度选择器：v = E/B；三场匀速圆周：qE = mg
- 感应三件套：E = BLv，I = E/R总，F安 = B²L²v/R总
- 收尾速度：F = B²L²v_m/R总
- 电荷量：q = ΔΦ/R总 = BLx/R总；动量定理：BLq = mΔv
- 热：能量守恒；R 上分 Q·R/(R + r)
- 等宽双棒 = 完全非弹性碰撞：动量守恒，共速，Q = 动能损失
