## 0. 先补基础：5 个前置概念

### 0.1 速度是有方向的（矢量）
- 向右 5 m/s 和向左 5 m/s **不是同一个速度**。
- 做题时，我们先**规定一个正方向**（一般取初速度方向为正）。
- 和正方向相同 → 写正数；相反 → 写**负数**。
- 例：规定向右为正，一个球以 3 m/s 向左弹回，就写 v = **−3 m/s**。

> 💡 90% 的低分同学在这一章丢分，都是因为**反弹的速度忘了写负号**。

### 0.2 动能
- 公式：**Ek = ½mv²**
- m 是质量（kg），v 是速度大小（m/s），Ek 单位是焦耳（J）。
- 动能**没有方向**，永远 ≥ 0。速度是 −3 m/s，动能照样是 ½m×9。

### 0.3 重力势能
- 公式：**Ep = mgh**，h 是相对于你选的"零高度"的高度。
- 物体升高 h，重力势能增加 mgh；下降 h，就减少 mgh。
- g 一般取 10 m/s²（题目会说）。

### 0.4 弹性势能
- 弹簧被**压缩**或**拉长**时储存的能量。
- 高考**一般不要求用公式算**，而是用"能量守恒"倒推出来（后面会讲）。
- 关键：弹簧**原长**时弹性势能 = 0；压得越狠/拉得越长，弹性势能越大。

### 0.5 摩擦生热
- 两个物体之间有滑动摩擦，会把机械能变成**热（内能）**。
- 公式：**Q = f × s相对**
  - f 是滑动摩擦力，f = μN（水平面上 N = mg，所以 f = μmg）
  - **s相对** 是两个物体之间**相互滑过的距离**，不是对地面走过的距离！
- 举例：木块在木板上，木块对地走了 5 m，木板对地走了 3 m（同方向），那么相对滑动 s相对 = 5 − 3 = 2 m。

## 1. 动量与动量守恒

### 1.1 动量是什么
- 公式：**p = mv**（单位 kg·m/s）
- 大白话：物体"冲劲"有多大。一辆慢慢开的卡车（m 大）和一颗飞快的子弹（v 大），都有很大的动量。
- 动量**有方向**，方向和速度一样。所以算动量也要带正负号。

### 1.2 动量守恒定律
**内容**：如果一个系统（几个物体放在一起看）**不受外力，或外力的合力为零**，那么这个系统的**总动量保持不变**。

**公式**（两个物体）：

$$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$$

- 左边：作用**前**的总动量
- 右边：作用**后**的总动量
- v 带撇号（'）表示"后来的速度"

**大白话**：两个物体互相撞、互相推、互相拉，它们之间的力是"自己人的力"（内力），自己人推来推去，总的动量不会凭空变多变少。

### 1.3 什么时候能用动量守恒？（最重要！）
判断方法：**看系统受不受外力**。

| 情况 | 能不能用 | 典型例子 |
|---|---|---|
| ① 合外力 = 0 | ✅ 能 | 光滑水平面上两个木块相撞（重力和支持力抵消，没有摩擦） |
| ② 内力远大于外力 | ✅ 近似能 | 碰撞、爆炸、子弹打木块——时间极短，内力特别大，外力可以忽略 |
| ③ 某一方向合外力 = 0 | ✅ 只在这个方向能 | 小球冲上**光滑可动**的圆弧槽：竖直方向有重力，不守恒；**水平方向**没有外力，水平动量守恒 |
| ④ 有外力且不可忽略 | ❌ 不能 | 地面有摩擦且时间较长；物体撞墙（墙给外力） |

> 💡 **"系统"怎么选**：把互相作用的物体**一起**圈进来。比如木块和木板之间的摩擦力，圈在一起后就是内力，不影响动量守恒。

## 2. 能量守恒与机械能守恒

### 2.1 能量守恒（永远成立）
能量不会凭空产生，也不会凭空消失，只会**从一种形式变成另一种形式**。

$$E_{初} = E_{末} + Q$$

这里 Q 是"变成热的那部分"。

### 2.2 机械能守恒（有条件）
- 机械能 = 动能 + 重力势能 + 弹性势能
- **条件**：只有重力、弹簧弹力做功（**没有摩擦、没有碰撞粘连**）。
- 满足条件时：E机初 = E机末。

### 2.3 两者关系，一句话
- **没摩擦、没粘连** → 机械能守恒（Q = 0）
- **有摩擦或粘在一起** → 机械能减少，减少的那部分**全部变成了热 Q**

$$\text{减少的机械能} = Q = f \cdot s_{相对}$$

### 2.4 ⚠️ 动量守恒 ≠ 动能守恒
很多同学以为"动量守恒了，动能也守恒"——**错**！
- 两块橡皮泥撞在一起粘住：动量守恒 ✅，动能**减少**了 ❌（变成热和形变）。
- 只有"**弹性碰撞**"动能才守恒。

## 3. 两个守恒怎么配合？（本章核心思路）

> **动量守恒 → 求速度**
> **能量守恒 → 求高度、弹性势能、热量、相对位移（木板长度）**

一道题通常有 2 个未知数，所以需要 **2 个方程**：
- 一个**动量方程**
- 一个**能量方程**

**解题四步法**（每道题都按这个来）：

| 步骤 | 做什么 | 问自己 |
|---|---|---|
| 第 1 步：分过程 | 把整件事切成几段 | "这道题经历了几个阶段？下滑？碰撞？滑动？" |
| 第 2 步：判守恒 | 每一段分别判断 | "这一段外力为零吗？（动量）有摩擦吗？（能量）" |
| 第 3 步：找关键状态 | 找"共速"或"分离"时刻 | "题目问的'最大''最短''最高''恰好'对应什么时刻？" |
| 第 4 步：列方程求解 | 动量一条 + 能量一条 | "我规定正方向了吗？结果合理吗？" |

### 3.1 什么是"关键状态"？（得分关键）
| 题目说法 | 对应的物理状态 |
|---|---|
| 弹簧**压缩最短** / **伸长最长** / 弹性势能**最大** | 两物体**速度相同**（共速） |
| 滑块在可动槽上**到达最高点** | 滑块和槽**水平速度相同**（共速） |
| 木块**恰好不从木板上滑下** | 木块滑到木板末端时，**恰好共速** |
| 子弹**恰好没有打穿**木块 | 子弹到木块末端时，**恰好共速** |
| 系统损失的机械能**最多** | 共速时（完全非弹性） |
| 弹簧**恢复原长** / 滑块**离开**槽 | **分离**时刻，相当于发生了一次弹性碰撞 |

> 💡 **为什么"弹簧最短"就是"共速"？**
> 想象 A 追着压 B：A 比 B 快，两者越靠越近，弹簧越压越短；等到 A 和 B 一样快，就不再靠近了——这一刻弹簧最短。之后 B 比 A 快，两者分开，弹簧开始恢复。所以"最短"那一瞬间正好是"一样快"。

## 4. 三种碰撞，一张表看懂

| 碰撞类型 | 动量 | 动能 | 现象 | 例子 |
|---|---|---|---|---|
| 弹性碰撞 | 守恒 | **守恒**（不损失） | 撞完分开 | 钢球对撞、台球（理想） |
| 非弹性碰撞 | 守恒 | 减少一部分 | 撞完分开，但速度变小 | 一般的碰撞 |
| 完全非弹性碰撞 | 守恒 | **减少最多** | 撞完**粘在一起**，速度相同 | 橡皮泥、子弹嵌入木块 |

### 4.1 弹性碰撞公式（动碰静）
m₁ 以速度 v₀ 去撞**静止**的 m₂，碰后：

$$v_1' = \frac{m_1 - m_2}{m_1 + m_2}v_0 \qquad v_2' = \frac{2m_1}{m_1 + m_2}v_0$$

**记忆技巧**：
- 被撞的 m₂ 分子是 **2m₁**（"被撞的拿两倍撞人的"）
- 撞人的 m₁ 分子是 **m₁ − m₂**（"自己减别人"）
- 分母都是**总质量**

**三个特殊情况**（选择题常考）：
| 条件 | 结果 | 大白话 |
|---|---|---|
| m₁ = m₂ | v₁' = 0，v₂' = v₀ | **交换速度**（台球打正了，母球停住） |
| m₁ ≫ m₂ | v₁' ≈ v₀，v₂' ≈ 2v₀ | 大的撞小的，大的几乎不减速，小的被弹飞 |
| m₁ ≪ m₂ | v₁' ≈ −v₀，v₂' ≈ 0 | 小的撞大的（像球撞墙），原速弹回 |

<details>
<summary>📐 （选看）公式是怎么推出来的</summary>

动量守恒：m₁v₀ = m₁v₁' + m₂v₂' …①
动能守恒：½m₁v₀² = ½m₁v₁'² + ½m₂v₂'² …②

① 变形：m₁(v₀ − v₁') = m₂v₂'
② 变形：m₁(v₀ − v₁')(v₀ + v₁') = m₂v₂'²
两式相除：v₀ + v₁' = v₂' …③
把 ③ 代回 ① 即可解出上面两个公式。
③ 式也很有用：**弹性碰撞中，碰前相对速度 = 碰后相对速度（反向）**。
</details>

### 4.2 完全非弹性碰撞公式（动碰静，碰后粘在一起）

$$v_{共} = \frac{m_1v_0}{m_1 + m_2} \qquad \Delta E_{损} = \frac{m_1m_2v_0^2}{2(m_1+m_2)}$$

> 不想背 ΔE 公式也没关系：**ΔE = 碰前总动能 − 碰后总动能**，直接算就行。

### 4.3 判断一次碰撞"可不可能发生"——三条都要满足
1. **动量守恒**：碰前总动量 = 碰后总动量
2. **动能不增加**：碰后总动能 ≤ 碰前总动能（能量不能凭空变多）
3. **速度合理**：
   - 碰前：后面的必须比前面的快（不然追不上）
   - 碰后：如果两者同方向运动，**后面的不能比前面的快**（不然就穿过去了）

## 5. 七大模型逐个讲透

> 江苏大题基本都是这 7 个模型的组合。每个模型记住"动量怎么列、能量怎么列、关键状态是什么"。

### 模型 1：子弹打木块
**情景**：子弹（m）以 v₀ 射入静止在光滑水平面上的木块（M），最后留在木块里。

| | 内容 |
|---|---|
| 动量 | 守恒：mv₀ = (m+M)v |
| 能量 | 不守恒机械能，有摩擦生热：½mv₀² = ½(m+M)v² + Q |
| 热量 | Q = f·d，d 是子弹**打进木块的深度**（相对位移） |
| 关键状态 | 子弹停在木块里 = 共速 |
| 打穿条件 | 如果到达木块末端时还没共速，就打穿了 |

### 模型 2：板块模型（滑块-木板）
**情景**：光滑地面上放长木板（M），小物块（m）以 v₀ 滑上木板，两者间有摩擦 μ。

| | 内容 |
|---|---|
| 动量 | 守恒（地面光滑，摩擦力是内力）：mv₀ = (m+M)v共 |
| 能量 | ½mv₀² = ½(m+M)v共² + μmg·L相对 |
| 关键状态 | 共速后一起运动，不再相对滑动 |
| 常问 | 木板至少多长？ → L = Q ÷ (μmg) |

> ⚠️ 如果**地面也有摩擦**，系统受外力，**动量不守恒**！要改用牛顿定律分段算。

### 模型 3：弹簧连接两物体
**情景**：光滑水平面上，B 静止且连着弹簧，A 以 v₀ 撞向弹簧。

| | 内容 |
|---|---|
| 动量 | 全程守恒 |
| 能量 | 全程**机械能守恒**（动能 ⇄ 弹性势能，没有热） |
| 关键状态 1 | **弹簧最短**：A、B 共速，弹性势能最大 |
| 关键状态 2 | **弹簧恢复原长**：A、B 分开，结果 = 弹性碰撞公式 |
| 弹性势能最大值 | Ep最大 = 碰前总动能 − 共速时总动能 |

### 模型 4：光滑可动圆弧槽 / 斜面
**情景**：光滑水平面上放着一个**能动的**光滑圆弧槽（M），小球（m）以 v₀ 冲上去。

| | 内容 |
|---|---|
| 动量 | **只有水平方向守恒**（竖直方向受重力） |
| 能量 | 机械能守恒（全光滑） |
| 关键状态 1 | **最高点**：小球和槽**水平速度相同**（小球此时不是静止的！） |
| 关键状态 2 | **小球离开槽**：等效弹性碰撞 |
| 最大高度 | h = Mv₀² / [2g(m+M)] |

> ⚠️ 如果槽是**固定**的，就只是普通机械能守恒：mgh = ½mv₀²。看清题目说"固定"还是"可自由滑动"。

### 模型 5：人船模型
**情景**：人站在静止的船上，从船头走到船尾，水的阻力不计。

| | 内容 |
|---|---|
| 动量 | 守恒，而且**总动量始终为 0** |
| 结论 | 人往前走，船往后退；m人·x人 = M船·x船 |
| 几何关系 | x人 + x船 = 船长 L |

### 模型 6：反冲 / 爆炸
- 原来静止，炸开后：0 = m₁v₁ + m₂v₂ → 两块**反向**飞出，**质量小的跑得快**。
- 爆炸时**化学能变成动能**，所以动能**增加**（这是唯一动能会增加的情况）。

### 模型 7：多过程组合（大题最爱）
例如：**光滑圆弧下滑 → 碰撞 → 滑上木板 → 压弹簧**。
**做法**：一段一段来，每一段用最合适的规律，**上一段的末速度就是下一段的初速度**。

| 阶段 | 常用规律 |
|---|---|
| 沿光滑圆弧下滑 | 机械能守恒：mgh = ½mv² |
| 碰撞瞬间 | 动量守恒（+ 弹性的话动能守恒） |
| 在粗糙木板上滑 | 动量守恒 + 能量守恒（有 Q） |
| 压弹簧 | 动量守恒 + 机械能守恒 |

## 6. 例题：从易到难，一步一步做

### 例 1 ★ 完全非弹性碰撞（热身）
光滑水平面上，质量 2 kg 的 A 以 3 m/s 向右运动，撞上静止的 1 kg 的 B，撞后粘在一起。求：(1) 共同速度；(2) 碰撞损失的机械能。

**第 1 步：判守恒**
光滑水平面，没有摩擦；碰撞时间极短 → **动量守恒** ✅。粘在一起 → 动能**不守恒**，有损失。

**第 2 步：规定正方向**
规定向右为正。

**第 3 步：列动量方程**
碰前：A 的动量 2×3 = 6，B 静止动量 0
碰后：两者一起，速度 v
6 + 0 = (2 + 1)v → **v = 2 m/s**（正数，说明向右）

**第 4 步：算损失**
碰前动能：½×2×3² = 9 J
碰后动能：½×3×2² = 6 J
损失：9 − 6 = **3 J**

> ✍️ 检验：用公式 ΔE = m₁m₂v₀²/[2(m₁+m₂)] = 2×1×9/(2×3) = 3 J ✓

---

### 例 2 ★★ 碰撞可能性（选择题）
光滑水平面上，A（1 kg）以 6 m/s 撞静止的 B（2 kg）。碰后速度**可能**是：
A. vA = 2 m/s，vB = 2 m/s
B. vA = −2 m/s，vB = 4 m/s
C. vA = 4 m/s，vB = 1 m/s
D. vA = −4 m/s，vB = 5 m/s

**先算碰前的"标准"**：
- 总动量：1×6 = **6 kg·m/s**
- 总动能：½×1×36 = **18 J**

**逐项用"三条判据"检查**：

| 选项 | ① 动量 = 6？ | ② 动能 ≤ 18？ | ③ 速度合理？ | 结论 |
|---|---|---|---|---|
| A | 1×2+2×2 = 6 ✅ | ½×1×4+½×2×4 = 6 ✅ | 一样快，粘在一起 ✅ | 可能 |
| B | 1×(−2)+2×4 = 6 ✅ | ½×1×4+½×2×16 = 18 ✅ | A 弹回，B 向前 ✅ | 可能 |
| C | 1×4+2×1 = 6 ✅ | 8+1 = 9 ✅ | A 在后面却比 B 快（4>1），会穿过 B ❌ | 不可能 |
| D | 1×(−4)+2×5 = 6 ✅ | 8+25 = 33 > 18 ❌ | — | 不可能 |

**答案：AB**

> 💡 规律：A 是完全非弹性（损失最多），B 是弹性（不损失）。**真实结果一定在这两种之间**。

### 例 3 ★★ 板块模型
光滑水平面上放长木板 M = 2 kg，物块 m = 1 kg 以 v₀ = 6 m/s 从左端滑上木板，两者间动摩擦因数 μ = 0.2，g = 10 m/s²。求：
(1) 最终共同速度；(2) 系统产生的热量；(3) 物块不滑下，木板至少多长；(4) 相对滑动多长时间。

**分析**：物块受木板向左的摩擦力，减速；木板受物块向右的摩擦力，加速。直到两者一样快，就不再相对滑动。

**(1) 共同速度**
系统 = 物块 + 木板。地面光滑，摩擦力是内力 → 动量守恒。
规定向右为正：
1×6 + 2×0 = (1+2)v → **v = 2 m/s**

**(2) 热量**
有摩擦 → 用能量守恒：减少的动能 = 热量
Q = ½×1×6² − ½×3×2² = 18 − 6 = **12 J**

**(3) 木板最短长度**
Q = f × s相对，f = μmg = 0.2×1×10 = 2 N
s相对 = 12 ÷ 2 = 6 m
物块恰好滑到木板最右端时共速，所以木板至少 **6 m**。

**(4) 时间**
物块的加速度：a = f/m = 2/1 = 2 m/s²（减速）
从 6 m/s 减到 2 m/s：t = (6 − 2)/2 = **2 s**

> ✍️ 检验（选看）：2 s 内物块对地位移 = (6+2)/2×2 = 8 m；木板加速度 2/2 = 1 m/s²，位移 = ½×1×4 = 2 m；相对位移 8 − 2 = 6 m ✓ 和 (3) 一致。

### 例 4 ★★★ 弹簧模型（江苏 2024 T9、2026 T16 同类）
光滑水平面上，B（1 kg）静止，左侧连一根轻弹簧；A（2 kg）以 3 m/s 向右运动并压缩弹簧。求：
(1) 弹簧的最大弹性势能；(2) 弹簧恢复原长时 A、B 的速度。

**(1) 最大弹性势能**
- "弹性势能最大" = "弹簧最短" = **A、B 共速**
- 动量守恒：2×3 = (2+1)v → v = 2 m/s
- 机械能守恒（没摩擦）：碰前动能 = 共速时动能 + 弹性势能
  ½×2×3² = ½×3×2² + Ep
  9 = 6 + Ep → **Ep = 3 J**

**(2) 恢复原长时**
- 弹簧原长 → 弹性势能又变回 0 → 总动能 = 原来的 9 J → 和**弹性碰撞**一模一样
- 直接用公式（m₁ = 2，m₂ = 1，v₀ = 3）：
  vA = (2−1)/(2+1)×3 = **1 m/s**（向右）
  vB = 2×2/(2+1)×3 = **4 m/s**（向右）
- 检验：动量 2×1+1×4 = 6 ✓；动能 ½×2×1+½×1×16 = 9 J ✓

### 例 5 ★★★ 光滑可动圆弧槽
光滑水平面上有质量 M = 3 kg 的光滑圆弧槽（足够高，可自由滑动），m = 1 kg 的小球以 v₀ = 4 m/s 冲上槽，g = 10 m/s²。求：
(1) 小球上升的最大高度；(2) 小球离开槽时两者速度。

**(1) 最大高度**
- ⚠️ 竖直方向受重力，**只有水平方向动量守恒**
- 最高点：小球和槽**水平速度相同**（不是小球速度为 0！）
- 水平动量守恒：1×4 = (1+3)v → v = 1 m/s
- 机械能守恒：½×1×4² = ½×4×1² + 1×10×h
  8 = 2 + 10h → **h = 0.6 m**

**(2) 离开时**
- 小球从槽上滑下来离开 → 整个过程没有能量损失 → 等效弹性碰撞
- v球 = (1−3)/(1+3)×4 = **−2 m/s**（负号：向左）
- v槽 = 2×1/(1+3)×4 = **2 m/s**（向右）

### 例 6 ★★★★ 多过程综合（江苏计算题风格）
小物块 m = 1 kg 从高 h = 1.8 m 的**光滑**圆弧顶端由静止滑下，到达光滑水平面后，滑上静止的长木板 M = 2 kg 的上表面（木板上表面与圆弧底端等高）。物块与木板间 μ = 0.2，地面光滑，g = 10 m/s²。
(1) 物块到圆弧底端时的速度；
(2) 若物块恰好不滑离木板，木板长度；
(3) 若木板长只有 4 m，物块离开木板时两者的速度。

**先分过程**：
- 过程 Ⅰ：沿光滑圆弧下滑 → 机械能守恒
- 过程 Ⅱ：在木板上滑动 → 动量守恒 + 能量守恒（有摩擦热）

**(1)** 过程 Ⅰ，机械能守恒：
mgh = ½mv₀² → 1×10×1.8 = ½×1×v₀² → v₀² = 36 → **v₀ = 6 m/s**

**(2)** 过程 Ⅱ，和例 3 完全一样：
v共 = 2 m/s，Q = 12 J，L = 12 ÷ 2 = **6 m**

**(3)** 木板只有 4 m < 6 m → 还没共速物块就滑出去了。设离开时物块速度 v₁、木板速度 v₂（都向右）。

- 动量守恒：1×6 = 1×v₁ + 2×v₂ → **v₁ = 6 − 2v₂** …①
- 能量守恒：产生的热 Q = μmg×L = 2×4 = 8 J
  ½×1×36 = ½×1×v₁² + ½×2×v₂² + 8
  18 = ½v₁² + v₂² + 8 …②
- 把 ① 代入 ②：
  18 = ½(6 − 2v₂)² + v₂² + 8
  18 = ½(36 − 24v₂ + 4v₂²) + v₂² + 8
  18 = 18 − 12v₂ + 2v₂² + v₂² + 8
  0 = 3v₂² − 12v₂ + 8
- 解方程：v₂ = [12 ± √(144 − 96)]/6 = (12 ± √48)/6 = 2 ± (2√3)/3
- **选哪个根？** 物块离开时必须比木板快（不然不会滑出），所以 v₂ 取小的那个：
  v₂ = 2 − (2√3)/3 ≈ **0.85 m/s**
  v₁ = 6 − 2v₂ = 2 + (4√3)/3 ≈ **4.31 m/s**
- 检验：v₁ > v₂ ✓

> 💡 解出两个根时，一定要用"**物理上是否合理**"来取舍。这是大题常见的得分点。

## 7. 最容易丢分的 10 个坑

| # | 错误 | 正确做法 |
|---|---|---|
| 1 | 反弹速度忘写负号 | 列方程前**先写"规定 ×× 为正方向"** |
| 2 | 以为动量守恒，动能也守恒 | 只有弹性碰撞动能守恒 |
| 3 | 摩擦热用了对地位移 | Q = f × **相对**位移 |
| 4 | 地面有摩擦还用动量守恒 | 先查外力，地面粗糙就不能直接用 |
| 5 | 可动槽最高点以为速度为 0 | 最高点是**水平共速** |
| 6 | 固定槽和可动槽搞混 | 固定槽：只用机械能守恒 |
| 7 | 子弹射入木块后摆起，全过程用机械能守恒 | **嵌入瞬间有损失**，要分两段：先动量守恒，再机械能守恒 |
| 8 | 弹簧最短/最长没想到共速 | 最短、最长 = 共速；原长 = 分离 |
| 9 | 解出两个根随便选一个 | 用速度大小、方向是否合理来取舍 |
| 10 | 多过程题一口气列一个方程 | **分段**，上段末速度 = 下段初速度 |

**题 2** ★★ 光滑水平面上，木板 M = 3 kg 静止，物块 m = 1 kg 以 4 m/s 滑上木板，μ = 0.3，g = 10 m/s²。求共同速度、产生的热量、木板最短长度。

**题 4** ★ 判断对错：
(1) 小球从空中落到地面弹起，小球的动量守恒。

(3) 爆炸过程中系统动能会增加。

## 9. 一页纸背诵版

```
【判断】
  动量守恒：系统合外力 = 0 / 内力 ≫ 外力 / 某方向合外力 = 0（只该方向）
  机械能守恒：没摩擦、没粘连
  有摩擦：减少的机械能 = Q = f × s相对

【分工】
  动量 → 求速度
  能量 → 求高度、弹性势能、热量、木板长度

【关键状态】
  共速：弹簧最短/最长、槽上最高点、恰好不滑出、子弹恰好不穿出 → 损失最多 / Ep最大
  分离：弹簧原长、离开槽 → 等效弹性碰撞

【公式】
  弹性（动碰静）：v1' = (m1−m2)v0/(m1+m2)   v2' = 2m1v0/(m1+m2)
  完全非弹性：v共 = m1v0/(m1+m2)
  人船：m·x人 = M·x船，x人 + x船 = L

【碰撞可能性】动量守恒 + 动能不增加 + 速度合理

【做题四步】分过程 → 判守恒 → 找关键状态 → 列两方程（先定正方向！）
```
