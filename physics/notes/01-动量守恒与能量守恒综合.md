# 动量守恒与能量守恒的综合运用

> 江苏卷地位：2024 T9（U 形板 + 弹簧，选择）、2025 T14（动量守恒 + 机械能守恒，13 分计算）、2026 T16（多球弹簧碰撞，压轴）连续三年出现。频率：**高**；难度：★★★★☆。

## 一、两条主线

| | 动量守恒 | 能量守恒 |
|---|---|---|
| 研究什么 | 系统总动量（矢量） | 系统总能量（标量） |
| 条件 | 合外力为零；或内力 ≫ 外力（碰撞、爆炸）；或某方向合外力为零（只在该方向守恒） | 永远成立；**机械能守恒**要求只有重力/弹力做功 |
| 表达式 | m1v1+m2v2 = m1v1'+m2v2'（先定正方向） | E初 = E末 + Q，Q = f·s相对 |
| 解决什么 | 速度关系 | 位移（相对位移）、高度、弹性势能、热量 |

⚠️ 动量守恒 ≠ 动能守恒。只有**弹性碰撞**动能才守恒；有摩擦、粘在一起、子弹嵌入，动能都会减少。

## 二、核心公式

1. **弹性碰撞（m1 以 v0 撞静止 m2）**
   v1' = (m1−m2)v0/(m1+m2)，v2' = 2m1v0/(m1+m2)
   - 等质量：交换速度
   - m1 ≫ m2：v1'≈v0，v2'≈2v0
   - m1 ≪ m2：原速弹回
2. **完全非弹性碰撞**
   v共 = m1v0/(m1+m2)，ΔEk = m1m2v0² / [2(m1+m2)]（这是损失的最大值）
3. **摩擦生热**：Q = f·s相对（相对位移，不是对地位移）
4. **人船模型**：m·x1 = M·x2，x1 + x2 = L
5. **曲面槽最大高度**：h = Mv0² / [2g(m+M)]

## 三、碰撞可能性"三判据"

1. 动量守恒；
2. 总动能不增加；
3. 速度合理：碰前后车追前车（v后>v前）；碰后若同向，后面的不能比前面的快。

## 四、解题四步（对应流程图）

1. **选系统、分过程**：碰撞瞬间、滑动过程、上升过程分开。
2. **判守恒**：动量看外力，机械能看有没有摩擦/非弹性。
3. **抓关键状态**：共速（弹簧最短、滑块最高、相对静止）或分离（弹簧原长、离开曲面）。
4. **联立方程**：动量一条 + 能量一条，最后检验。

## 五、易错点

- 忘记规定正方向，反弹速度没带负号。
- 摩擦热用了对地位移（应是相对位移）。
- 曲面槽可动时，以为滑块在最高点速度为 0（实际是与槽共有水平速度）。
- 子弹打木块过程中把"木块+子弹摆起"的整个过程当成机械能守恒（嵌入瞬间有损失）。
- 弹簧"最短"和"最长"都对应共速；"原长"对应速度极值。
- 多过程题只对一个阶段用了守恒，其余阶段条件不成立（例如有墙、地面有摩擦）。

## 六、例题

### 例 1　碰撞可能性（选择）
光滑水平面上，A（1 kg）以 6 m/s 撞静止的 B（2 kg）。碰后速度可能是：
A. vA=2 m/s，vB=2 m/s　B. vA=−2 m/s，vB=4 m/s　C. vA=4 m/s，vB=1 m/s　D. vA=−4 m/s，vB=5 m/s

**解**：碰前 p=6 kg·m/s，Ek=18 J。
- A：p=2+4=6 ✓，Ek=2+4=6 J ≤ 18 ✓，共速 ✓ → 可能（完全非弹性）
- B：p=−2+8=6 ✓，Ek=2+16=18 J ✓ → 可能（弹性）
- C：p=4+2=6 ✓，但 vA>vB 且同向，A 穿过 B ✗
- D：p=−4+10=6 ✓，Ek=8+25=33 J > 18 ✗

**答案：AB**

### 例 2　板块模型
光滑水平面上放长木板 M=2 kg，物块 m=1 kg 以 v0=6 m/s 滑上木板左端，μ=0.2，g=10 m/s²。求：(1) 共同速度；(2) 系统产生的热量；(3) 木板至少多长；(4) 相对滑动时间。

**解**：
(1) mv0=(m+M)v → v = 6/3 = **2 m/s**
(2) Q = ½·1·6² − ½·3·2² = 18 − 6 = **12 J**
(3) Q = μmg·L → L = 12/(0.2×1×10) = **6 m**
(4) 物块 a=μg=2 m/s²，t=(6−2)/2 = **2 s**

### 例 3　弹簧连接（江苏 2024 T9、2026 T16 同类）
光滑水平面上，B（1 kg）静止，左端连轻弹簧；A（2 kg）以 3 m/s 向右压弹簧。求：(1) 弹簧最大弹性势能；(2) 弹簧恢复原长时 A、B 速度。

**解**：
(1) 最短时共速：2×3 = 3v → v=2 m/s；Ep = ½·2·9 − ½·3·4 = 9 − 6 = **3 J**
(2) 原长 ≡ 弹性碰撞：vA=(2−1)/3×3 = **1 m/s**，vB=2×2/3×3 = **4 m/s**
检验：½·2·1 + ½·1·16 = 9 J ✓

### 例 4　光滑可动圆弧槽
光滑水平面上有质量 M=3 kg 的光滑圆弧槽（足够高），m=1 kg 的小球以 v0=4 m/s 冲上槽，g=10 m/s²。求：(1) 小球能上升的最大高度；(2) 小球离开槽时两者速度。

**解**：
(1) 水平动量守恒：1×4 = 4v → v=1 m/s；mgh = ½·1·16 − ½·4·1 = 6 J → h = **0.6 m**
(2) 等效弹性碰撞：v球=(1−3)/4×4 = **−2 m/s**（向左），v槽=2×1/4×4 = **2 m/s**

### 例 5　多过程计算（江苏计算题风格）
小物块 m=1 kg 从高 h=1.8 m 的光滑圆弧顶端静止滑下，滑到光滑水平面后滑上静止的长木板 M=2 kg（与圆弧底等高，不粘连），物块与木板间 μ=0.2，地面光滑，g=10 m/s²。
(1) 物块到圆弧底端的速度；(2) 物块不滑离木板，木板最短长度；(3) 若木板长只有 4 m，物块离开木板时两者速度。

**解**：
(1) mgh=½mv0² → v0 = √(2×10×1.8) = **6 m/s**
(2) 同例 2：v共=2 m/s，Q=12 J，L最短 = **6 m**
(3) 设离开时物块 v1、木板 v2：
   动量：6 = v1 + 2v2
   能量：½·36 = ½v1² + ½·2v2² + μmg·L = ½v1² + v2² + 8
   代入 v1 = 6 − 2v2：18 = ½(6−2v2)² + v2² + 8 → 3v2² − 12v2 + 8 = 0
   v2 = (12 − √48)/6 = 2 − (2√3)/3 ≈ **0.85 m/s**（取小根：物块仍比木板快）
   v1 = 6 − 2v2 = 2 + (4√3)/3 ≈ **4.31 m/s**

## 七、一句话总结
**动量管速度，能量管位移/高度/热量；共速是极值，分离是弹性。**
