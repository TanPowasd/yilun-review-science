## 0. 先记住：所有变式都只是三件事变了

题目再怎么变，你只要问自己三个问题：

| 问题 | 怎么判断 | 变了会怎样 |
|---|---|---|
| ① **系统受不受外力？** | 地面有没有摩擦？有没有墙、挡板、竖直方向的力？ | 有外力 → 动量不守恒（或只在某个方向守恒，或只在某一段守恒） |
| ② **有没有生热？** | 有摩擦、粘在一起、子弹打入 → 有热 | 有热 → 不能用机械能守恒，要用"能量守恒 + Q" |
| ③ **关键状态变成了哪个？** | 共速？分离？滑出？撞墙？最高点？ | 不同关键状态 → 列方程的"末状态"不同 |

> 大白话：**模型是骨架，变式只是换了外力、换了生热、换了终点。** 先把这三问答出来，再动笔列方程。

## 1. 碰撞的拓展

### 1.1 变式一：动碰动的弹性碰撞（两个都在动）

**情景**：m₁ 以 v₁、m₂ 以 v₂ 在同一直线上运动（v₂ 可以为负，表示向左），发生弹性碰撞。

**两个方程**（字母式）：
- 动量守恒：m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′
- 动能守恒：½m₁v₁² + ½m₂v₂² = ½m₁v₁′² + ½m₂v₂′²

**解出来的结论**（会背更快，不会背就解上面两个方程）：
- v₁′ = [(m₁ − m₂)v₁ + 2m₂v₂] / (m₁ + m₂)
- v₂′ = [(m₂ − m₁)v₂ + 2m₁v₁] / (m₁ + m₂)

> 记法：v₁′ 的式子里，"自己的速度"前面是 (m₁ − m₂)，"对方的速度"前面是 2m₂。v₂′ 把下标 1、2 对调即可。当 v₂ = 0 时，就退回 01 里"动碰静"的公式。

**小例题**：m₁ = 1 kg、v₁ = 4 m/s；m₂ = 2 kg、v₂ = 1 m/s（同向右），弹性碰撞，求碰后速度。
- v₁′ = [(m₁ − m₂)v₁ + 2m₂v₂] / (m₁ + m₂)
  代入：v₁′ = [(1 − 2)×4 + 2×2×1] / (1 + 2) = 0 / 3 = **0**
- v₂′ = [(m₂ − m₁)v₂ + 2m₁v₁] / (m₁ + m₂)
  代入：v₂′ = [(2 − 1)×1 + 2×1×4] / 3 = 9 / 3 = **3 m/s**
- **检验**（考场上务必做一下，10 秒钟）：
  碰前动量 1×4 + 2×1 = 6，碰后 1×0 + 2×3 = 6 ✓；
  碰前动能 ½×1×4² + ½×2×1² = 9 J，碰后 0 + ½×2×3² = 9 J ✓。

### 1.2 变式二：三个"特殊质量"结论（选择题秒杀）

动碰静弹性碰撞（m₁ 以 v₀ 撞静止的 m₂）：

| 条件 | 结论 | 生活例子 |
|---|---|---|
| m₁ = m₂ | **交换速度**：v₁′ = 0，v₂′ = v₀ | 台球正碰，母球停下，目标球以原速飞出 |
| m₁ ≫ m₂ | v₁′ ≈ v₀，v₂′ ≈ 2v₀ | 卡车撞乒乓球，乒乓球以两倍速度飞出 |
| m₁ ≪ m₂ | v₁′ ≈ −v₀，v₂′ ≈ 0 | 乒乓球撞墙，原速弹回 |

> 为什么？把条件代进 v₁′ = (m₁ − m₂)v₀/(m₁ + m₂)、v₂′ = 2m₁v₀/(m₁ + m₂) 就能看出来。比如 m₁ = m₂ 时分子 m₁ − m₂ = 0。

### 1.3 变式三：不知道是哪种碰撞——求"速度范围"

**题型**："A 与静止的 B 碰撞，碰后 B 的速度可能是多少？"——题目没说是哪种碰撞。

**思路**：真实碰撞介于两个极端之间：
- **完全非弹性**（粘在一起）：B 得到的速度**最小**
- **弹性**：B 得到的速度**最大**

**小例题**：A（1 kg，6 m/s）撞静止的 B（2 kg）。
- 完全非弹性：m_A v₀ = (m_A + m_B)v
  代入：1×6 = (1 + 2)v → v = **2 m/s**（B 的最小值）
- 弹性：v_B = 2m_A v₀ / (m_A + m_B)
  代入：v_B = 2×1×6 / 3 = **4 m/s**（B 的最大值）
- 结论：**2 m/s ≤ v_B ≤ 4 m/s**；对应 A 的速度在 2 m/s 到 −2 m/s 之间。

## 2. 子弹打木块的拓展

### 2.1 变式一：子弹打穿木块

**先判断会不会打穿**：
1. 先**假设**子弹留在木块里，算出共速和此时需要的相对位移 d。
2. 如果 d > 木块长度 L → 说明还没共速子弹就从另一端出去了 → **打穿**。

**打穿后的方程**（末状态：子弹速度 v₁，木块速度 v₂，相对位移 = L）：
- 动量：mv₀ = mv₁ + Mv₂
- 能量：½mv₀² = ½mv₁² + ½Mv₂² + fL

**小例题**：子弹 m = 0.1 kg，v₀ = 100 m/s；木块 M = 0.9 kg，长 L = 0.15 m，静止在光滑水平面上；子弹受阻力 f = 2250 N（恒定）。

**第 1 步：假设不打穿**
- mv₀ = (m + M)v
  代入：0.1×100 = (0.1 + 0.9)v → v = 10 m/s
- Q = ½mv₀² − ½(m + M)v²
  代入：Q = ½×0.1×100² − ½×1×10² = 500 − 50 = 450 J
- Q = f·d → d = Q / f
  代入：d = 450 / 2250 = 0.2 m
- 0.2 m > 0.15 m → **会打穿**。

**第 2 步：按打穿列方程**
- 动量：mv₀ = mv₁ + Mv₂
  代入：0.1×100 = 0.1v₁ + 0.9v₂ → v₁ = 100 − 9v₂ ……①
- 能量：½mv₀² = ½mv₁² + ½Mv₂² + fL
  代入：500 = 0.05v₁² + 0.45v₂² + 2250×0.15 → 0.05v₁² + 0.45v₂² = 162.5 ……②
- 把①代入②，整理得：v₂² − 20v₂ + 75 = 0 → v₂ = 5 或 v₂ = 15
- **舍根**：v₂ = 15 时 v₁ = −35（子弹倒飞回来，不可能；而且穿出后子弹必须比木块快）。
- 所以 **v₂ = 5 m/s，v₁ = 55 m/s**。

> 为什么要舍根？二次方程会给两个解，物理上只有一个对。判据：**穿出时子弹速度 ≥ 木块速度，且都向右**。

### 2.2 变式二：木块固定 vs 木块可动——打入深度比较

| | 木块固定 | 木块可动（光滑面） |
|---|---|---|
| 动量 | 不守恒（固定物受外力） | 守恒 |
| 能量 | f·d₀ = ½mv₀²（动能全变热） | f·d = ½mv₀² − ½(m + M)v² |
| 深度 | d₀ = mv₀² / (2f) | d = d₀ × M / (m + M)，**更浅** |

**代入上题数据**：
- 固定：d₀ = mv₀² / (2f)，代入：d₀ = 0.1×100² / (2×2250) ≈ 0.222 m
- 可动：d = d₀ × M / (m + M)，代入：d = 0.222 × 0.9 / 1 = 0.2 m ✓（和上面算的一致）

> 大白话：木块能被推着走，子弹的动能有一部分变成了木块的动能，用来"钻洞"的就少了，所以打得浅。

## 3. 板块模型的拓展

### 3.1 变式一：木板不够长——物块滑出

**判断**：先假设不滑出，算出需要的相对滑动距离 L需；若 L需 > 板长 L，则滑出。

**滑出时的方程**（相对位移 = 板长 L）：
- 动量：mv₀ = mv₁ + Mv₂
- 能量：½mv₀² = ½mv₁² + ½Mv₂² + μmgL

**小例题**：物块 m = 1 kg 以 v₀ = 6 m/s 滑上静止木板 M = 2 kg，μ = 0.2，地面光滑，板长 L = 4.5 m。
- 假设不滑出（01 里算过）：需要 L需 = 6 m > 4.5 m → **会滑出**。
- 动量：mv₀ = mv₁ + Mv₂
  代入：1×6 = v₁ + 2v₂ → v₁ = 6 − 2v₂
- 能量：½mv₀² = ½mv₁² + ½Mv₂² + μmgL
  代入：18 = ½v₁² + v₂² + 0.2×1×10×4.5 → ½v₁² + v₂² = 9
- 整理：3v₂² − 12v₂ + 9 = 0 → v₂ = 1 或 3
- 舍根：v₂ = 3 时 v₁ = 0，物块比木板慢，不可能"从前端滑出"。
- 所以 **v₁ = 4 m/s（物块），v₂ = 1 m/s（木板）**。

### 3.2 变式二：反过来——木板运动，物块静止放上去

**情景**：木板 M 以 v₀ 运动，把静止的小物块 m 轻放在木板上。

- 方向分析：物块相对木板**向后**滑，摩擦力让物块加速、木板减速。
- 动量：Mv₀ = (M + m)v
- 能量：Q = ½Mv₀² − ½(M + m)v²，Q = μmg·L相对

**小例题**：M = 2 kg，v₀ = 3 m/s，m = 1 kg，μ = 0.2。
- Mv₀ = (M + m)v，代入：2×3 = 3v → v = 2 m/s
- Q = ½Mv₀² − ½(M + m)v²，代入：Q = ½×2×3² − ½×3×2² = 9 − 6 = 3 J
- L相对 = Q / (μmg)，代入：L相对 = 3 / (0.2×1×10) = 1.5 m
- 物块在木板上的位置：**离放上去的点向后 1.5 m**。

### 3.3 变式三：木板撞墙（江苏大题常见）

**情景**：物块和木板已经共速向右运动，木板撞到墙后**原速反弹**（弹性碰撞，物块不碰墙）。

**关键**：
- **撞墙瞬间**：墙给木板一个很大的力 → 系统动量**不守恒**；但时间极短，物块速度来不及变。
- **撞墙之后**：墙不再起作用，物块 + 木板系统动量又守恒了。
- 撞墙后系统总动量 = −Mv + mv，**谁质量大，最终就往谁的方向走**。

**小例题**：M = 2 kg，m = 1 kg，μ = 0.2，一起以 v = 2 m/s 向右，木板撞墙后以 2 m/s 反弹。求最终共同速度和撞墙后生的热。
- 撞墙后瞬间：木板 −2 m/s，物块 +2 m/s
- 动量：m·v + M·(−v) = (m + M)v共
  代入：1×2 + 2×(−2) = 3v共 → v共 = −2/3 m/s（**向左**，因为木板更重）
- 能量：Q = ½(m + M)v² − ½(m + M)v共²
  代入：Q = ½×3×2² − ½×3×(2/3)² = 6 − 2/3 = **16/3 J ≈ 5.33 J**
- 最终向左走，离开墙，**不会再撞**。

> ⚠️ 若 m > M，撞后总动量向右，系统还会再撞墙，要分多次算——这种题通常问"第一次撞后"或用等比数列，先看清问什么。

### 3.4 变式四：地面也有摩擦（动量不守恒！）

- 地面摩擦是**外力** → 系统动量**不守恒**，不能用 mv₀ = (m + M)v。
- 方法：**牛顿第二定律分别求两个物体的加速度 → 运动学 → 找共速时刻**。
- 木板会不会动？比较：物块给木板的摩擦力 μ₁mg 与地面对木板的最大静摩擦力 μ₂(m + M)g：
  - μ₁mg ≤ μ₂(m + M)g → 木板**不动**
  - μ₁mg > μ₂(m + M)g → 木板动
- 能量还可以用：Q总 = μ₁mg·L相对 + μ₂(m + M)g·x板。

## 4. 弹簧模型的拓展

### 4.1 变式一：弹簧两端都连着物体——"最短"和"最长"

- 两个物体都与弹簧拴牢时，弹簧**最短**和**最长**两个时刻都是**共速**，弹性势能都最大，且**数值相等**。
- 例：A（2 kg，3 m/s）、B（1 kg，静止），弹簧两端都拴住：
  - m_A v₀ = (m_A + m_B)v，代入：2×3 = 3v → v = 2 m/s
  - Ep最大 = ½m_A v₀² − ½(m_A + m_B)v²，代入：Ep最大 = 9 − 6 = 3 J
  - 压缩到最短时 3 J，之后伸长到最长时还是 3 J。

### 4.2 变式二：弹簧一端固定在墙上

- 墙给弹簧外力 → 动量**不守恒**，只用**机械能守恒**。
- Ep最大 = ½mv₀²，物块以**原速率**弹回。
- 对比：B 能动时 Ep最大更小（一部分动能留在共速运动里）。

### 4.3 变式三：一物块靠墙，压缩后释放（经典两阶段）

**情景**：光滑面上，B 靠墙，A 与 B 用弹簧连接。把 A 向墙推、压缩弹簧（储存 Ep₀），然后释放。

| 阶段 | 发生什么 | 守恒情况 |
|---|---|---|
| 第 1 阶段：弹簧恢复原长前 | 墙推着 B，B 不动；A 被弹出 | 墙有外力 → **动量不守恒**；机械能守恒 |
| 第 2 阶段：弹簧原长后 | 弹簧开始拉 B，B 离开墙 | 动量守恒 + 机械能守恒 |

**小例题**：m_A = 1 kg，m_B = 3 kg，Ep₀ = 8 J。
- 第 1 阶段（到原长）：Ep₀ = ½m_A v_A²，代入：8 = ½×1×v_A² → v_A = 4 m/s
- 第 2 阶段，弹簧最长（共速）：m_A v_A = (m_A + m_B)v，代入：1×4 = 4v → v = 1 m/s
- Ep最大 = ½m_A v_A² − ½(m_A + m_B)v²，代入：Ep最大 = 8 − ½×4×1² = **6 J**
- B 的最大速度（弹簧再次原长，等效弹性碰撞）：v_B = 2m_A v_A / (m_A + m_B)，代入：v_B = 2×1×4 / 4 = **2 m/s**（此时 A 为 −2 m/s）

> ⚠️ 常错：以为第 2 阶段 Ep 还能回到 8 J。不能！B 离墙后系统有动量 4 kg·m/s，必须保留一部分动能，所以只有 6 J。

### 4.4 变式四：先碰撞粘连，再压弹簧（能量"分两次算"）

**情景**：C（1 kg，6 m/s）撞上 A（1 kg）并粘在一起，A 通过弹簧连着 B（2 kg），开始都静止。

- **碰撞瞬间**：时间极短，弹簧来不及形变，B **不参与**。
  m_C v₀ = (m_C + m_A)v₁，代入：1×6 = 2v₁ → v₁ = 3 m/s
  碰撞损失：ΔE = ½m_C v₀² − ½(m_C + m_A)v₁²，代入：ΔE = 18 − 9 = 9 J（变成热）
- **压弹簧到最短**：(m_C + m_A)v₁ = (m_C + m_A + m_B)v₂，代入：2×3 = 4v₂ → v₂ = 1.5 m/s
- Ep最大 = ½(m_C + m_A)v₁² − ½(m_C + m_A + m_B)v₂²，代入：Ep最大 = 9 − ½×4×1.5² = 9 − 4.5 = **4.5 J**

> ⚠️ 最大坑：用 18 − 4.5 = 13.5 J。**碰撞粘连那一下已经损失了 9 J 热**，压弹簧阶段只能从碰后的 9 J 算起。

## 5. 圆弧槽模型的拓展

### 5.1 变式一：小球从槽顶由静止滑下（槽可动）

**情景**：光滑水平面上，可自由滑动的光滑 1/4 圆弧槽 M，半径 R；小球 m 从槽顶静止释放。

- 水平动量守恒（初始总动量为 0）：0 = mv₁ − Mv₂（小球向右 v₁，槽向左 v₂）
- 机械能守恒：mgR = ½mv₁² + ½Mv₂²

**小例题**：m = 1 kg，M = 3 kg，R = 0.6 m，求小球到达槽底时两者速度和槽后退的距离。
- 0 = mv₁ − Mv₂，代入：v₁ = 3v₂
- mgR = ½mv₁² + ½Mv₂²，代入：1×10×0.6 = ½×1×(3v₂)² + ½×3×v₂² → 6 = 6v₂² → v₂ = 1 m/s，v₁ = 3 m/s
- **槽后退多少？**这是"人船模型"：m·x₁ = M·x₂，x₁ + x₂ = R
  代入：1·x₁ = 3·x₂，x₁ + x₂ = 0.6 → **x₂ = 0.15 m，x₁ = 0.45 m**

> 对比：槽固定时 v = √(2gR) = √12 ≈ 3.46 m/s，比 3 m/s 大——因为可动时一部分能量给了槽。

### 5.2 变式二：小球冲出槽口（槽不够高）

**情景**：小球 m = 1 kg 以 v₀ = 4 m/s 冲上 M = 3 kg 的可动光滑 1/4 圆弧槽，槽高 R = 0.4 m（01 里算过不够高时会升到 h = 0.6 m）。

- 离开槽口时：圆弧末端是竖直的 → 小球和槽**水平速度相同**，小球还多一个**竖直速度** v_y。
- 水平动量：mv₀ = (m + M)v_x，代入：1×4 = 4v_x → v_x = 1 m/s
- 机械能：½mv₀² = ½(m + M)v_x² + mgR + ½mv_y²
  代入：8 = ½×4×1² + 1×10×0.4 + ½×1×v_y² → v_y = 2 m/s
- 冲出后小球再上升：Δh = v_y² / (2g)，代入：Δh = 4 / 20 = 0.2 m，总高度 0.4 + 0.2 = 0.6 m ✓
- **结论**：小球相对槽是**竖直上抛**，会**落回槽口**，不会落到槽外。

### 5.3 变式三：小球滑回、离开槽——最终谁往哪走

- 离开槽时等效**弹性碰撞**：
  v₁′ = (m − M)v₀ / (m + M)，v₂′ = 2mv₀ / (m + M)
- 代入（m = 1，M = 3，v₀ = 4）：v₁′ = (1 − 3)×4 / 4 = **−2 m/s**（小球向左），v₂′ = 2×1×4 / 4 = **2 m/s**（槽向右）
- 判断方向的口诀：**m < M 球弹回；m = M 球停下；m > M 球继续向前**。

## 6. 人船模型的拓展

> 人船模型的本质：**两个物体、初始都静止、某方向不受外力** → 该方向位移满足 m₁x₁ = m₂x₂。
> 只要满足这三条，换什么"皮"都能用。

### 6.1 变式一：气球与绳梯

**情景**：质量 M 的气球静止在空中（浮力与总重力平衡），质量 m 的人从挂着的绳梯上往下爬。
- 竖直方向合外力为 0 → 竖直方向动量守恒（初始为 0）。
- 人下降 x人，气球上升 x球：m·x人 = M·x球
- 绳梯长度至少 = x人 + x球。

**小例题**：气球 M = 200 kg，人 m = 50 kg，离地 20 m，人要沿绳梯安全落地，绳梯至少多长？
- m·x人 = M·x球，代入：50×20 = 200·x球 → x球 = 5 m
- 绳梯长 = x人 + x球，代入：20 + 5 = **25 m**

### 6.2 变式二：滑块从光滑斜面体上滑下，斜面后退

**情景**：光滑水平面上放光滑斜面体 M，底边长 b；小滑块 m 从顶端滑到底端。
- 水平方向动量守恒（初始为 0）：m·x块 = M·x斜
- 几何：x块 + x斜 = b（两者水平位移之和等于底边长）
- 结论：x斜 = mb / (m + M)

**小例题**：m = 1 kg，M = 4 kg，b = 1 m。
- x斜 = mb / (m + M)，代入：x斜 = 1×1 / 5 = **0.2 m**（滑块水平走了 0.8 m）

### 6.3 判断能不能用人船模型

| 条件 | 例子 | 能用吗 |
|---|---|---|
| 初始都静止 + 某方向不受外力 | 人在船上走、球在可动槽里滑、斜面后退 | ✅ |
| 初始在动 | 船本来就在漂 | ❌（要用质心或分段算） |
| 水有阻力 / 地面有摩擦 | — | ❌ |

## 7. 反冲与爆炸的拓展

### 7.1 变式一：发射炮弹（炮车后退）

**情景**：炮车（不含炮弹）质量 M，静止在光滑地面，水平发射质量 m 的炮弹，炮弹对地速度 v。
- 0 = mv + MV → V = −mv / M
- 代入：m = 10 kg，v = 600 m/s，M = 500 kg：V = −10×600 / 500 = **−12 m/s**（向后）

> ⚠️ 若炮管**斜向上**发射：竖直方向地面支持力会突变 → 只有**水平方向**动量守恒：0 = mv cosθ + MV。
> ⚠️ 题目给的若是"炮弹相对炮车的速度 u"，则炮弹对地速度 = u + V，要先换算再列方程。

### 7.2 变式二：炮弹在最高点爆炸

**情景**：斜抛的炮弹（2 kg）到最高点时速度水平 20 m/s，炸成两块各 1 kg，其中一块恰好做自由落体（爆炸后速度为 0）。
- 爆炸时间极短，重力冲量可忽略 → 动量守恒：
  m总v = m₁v₁ + m₂v₂，代入：2×20 = 1×0 + 1×v₂ → v₂ = **40 m/s**
- 动能增加：ΔE = ½m₂v₂² − ½m总v²，代入：ΔE = ½×1×40² − ½×2×20² = 800 − 400 = **400 J**（来自化学能）
- 两块**同时落地**（竖直方向都从速度 0 开始下落，高度相同），所以水平距离之比 = 水平速度之比。

### 7.3 变式三：在运动中爆炸 / 分离

- 列式时用**对地速度**，原总动量不为 0：(m₁ + m₂)v = m₁v₁ + m₂v₂
- 只要题目说"炸成两块"，就要想到：**动量守恒，动能增加**，增加量 = 释放的化学能。

## 8. 两个"新面孔"：冲击摆、摆球小车

### 8.1 冲击摆（子弹打入悬挂的沙箱）

**情景**：子弹 m 以 v₀ 水平射入用细绳悬挂的沙箱 M，并留在里面，沙箱摆起最大高度 h。

| 阶段 | 规律 |
|---|---|
| 子弹打入（极短时间，绳子还竖直） | 动量守恒：mv₀ = (m + M)v（有热，机械能不守恒） |
| 一起向上摆 | 机械能守恒：½(m + M)v² = (m + M)gh |

**小例题**：m = 0.01 kg，M = 0.99 kg，v₀ = 400 m/s，求摆起高度。
- mv₀ = (m + M)v，代入：0.01×400 = 1×v → v = 4 m/s
- ½(m + M)v² = (m + M)gh → h = v² / (2g)，代入：h = 16 / 20 = **0.8 m**

> ⚠️ 不能把两段合成一个"½mv₀² = (m + M)gh"——打入那一下有大量生热。

### 8.2 摆球小车（光滑轨道上的小车挂着单摆）

**情景**：光滑水平面上的小车 M，车上用细绳挂着小球 m；小球获得水平初速度 v₀（车静止）。
- 它其实就是"圆弧槽"模型换了皮：**水平动量守恒 + 机械能守恒**，摆到最高点时**水平共速**。
- 最大高度：h = Mv₀² / [2g(m + M)]（和圆弧槽公式一模一样）

## 9. 易错点汇总

1. **撞墙 / 靠墙 / 地面摩擦 = 有外力**，这一段动量不守恒。但外力消失后的下一段可能又守恒了，要**分段判断**。
2. **碰撞粘连有热**：先碰撞再压弹簧（或再摆起），能量必须分两段算，不能一步从头算到尾。
3. **二次方程两个根，一定要舍根**：看"谁快谁慢、方向对不对"。
4. **"打穿 / 滑出"先假设不打穿**，用相对位移和长度比较再下结论。
5. **人船模型的位移是对地位移**，几何关系是"两者位移之和 = 相对位移"。
6. **斜向发射 / 竖直方向有力**：只在水平方向列动量守恒。
7. **木块固定和可动的深度不同**：可动时更浅，d = d₀·M/(m + M)。
8. **弹簧靠墙释放**：B 离墙后的最大弹性势能 < 初始弹性势能。
