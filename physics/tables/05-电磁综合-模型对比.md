# 05 电磁学大综合：模型对比

## A. 带电粒子

| 模型 | 运动 | 核心公式 | 常问 | 关键技巧 |
|---|---|---|---|---|
| 电场加速 | 匀加速直线 | qU = ½mv² | 末速度 | 动能定理，不管过程 |
| 电场偏转 | 类平抛 | y = U₂L²/(4U₁d)，tanθ = U₂L/(2U₁d) | 侧移、偏角、能否射出 | 与 q、m 无关；反向延长线过板长中点 |
| 磁场圆周 | 匀速圆周 | r = mv/(qB)，T = 2πm/(qB) | 半径、时间、出射点 | 找圆心→定半径→圆心角 = 偏转角 |
| 质谱仪 | 加速 + 半圆 | r = (1/B)√(2mU/q) | 落点、比荷 | 落点 x = 2r |
| 回旋加速器 | 多次加速 + 半圆 | E_k,max = q²B²R²/(2m) | 最大动能、加速次数 | 与加速电压无关；交变周期 = 2πm/(qB) |
| 速度选择器 | 匀速直线 | v = E/B | 能通过的速度 | 与电荷正负、q、m 无关 |
| 三场共存（带电小球） | 匀速圆周 / 匀速直线 | qE = mg；r = mv/(qB) | 电荷正负、半径 | 有洛伦兹力的直线运动一定匀速 |

## B. 电磁感应

| 模型 | 动量 | 末状态 | 求最大速度 | 求距离 / 电荷量 | 求热 |
|---|---|---|---|---|---|
| 单棒 + 恒力 F | 不守恒 | 匀速 | F = B²L²v_m/R总 | 动量定理 Ft − BLq = mv | Q = Fx − ½mv² |
| 单棒给初速度 | 不守恒 | 停下 | — | BLq = mv₀，x = qR总/(BL) | Q = ½mv₀² |
| 等宽双棒（光滑） | **守恒** | 共速 | — | 对一根棒 BLq = m₂v | Q = 动能损失 |
| 不等宽双棒 | 不守恒 | BL₁v₁ = BL₂v₂ | — | 两根棒分别用动量定理 | 能量守恒 |
| 线框穿磁场 | 不守恒 | 视情况 | 匀速：mg = B²L²v/R | q = ΔΦ/R | Q = mg·高度 − ΔE_k |

通用：E = BLv，I = E/(R + r)，F安 = B²L²v/R总；q = ΔΦ/R总；R 上的热 Q_R = Q·R/(R + r)。
