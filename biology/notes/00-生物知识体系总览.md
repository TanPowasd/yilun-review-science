## 三、必修1 分子与细胞

![[01-必修1-分子与细胞.png]]

### 第1章 走近细胞
- **大白话**：所有生物（除病毒）都由细胞构成；细胞分两大类。
- **必背句**
  1. 细胞学说由**施莱登和施万**建立，揭示了动物和植物的**统一性**，从而阐明了生物界的统一性。
  2. 魏尔肖补充：**细胞通过分裂产生新细胞**。
  3. 生命系统结构层次：**细胞 $\rightarrow$ 组织 $\rightarrow$ 器官 $\rightarrow$ 系统 $\rightarrow$ 个体 $\rightarrow$ 种群 $\rightarrow$ 群落 $\rightarrow$ 生态系统 $\rightarrow$ 生物圈**（植物没有"系统"层次；单细胞生物一个细胞就是一个个体）。
  4. 原核细胞和真核细胞最主要的区别：**有无以核膜为界限的细胞核**。
  5. 原核生物：**细菌、蓝细菌（蓝藻）、支原体、放线菌**；它们只有**核糖体**一种细胞器。
  6. **病毒没有细胞结构**，必须**寄生在活细胞**中才能生活和繁殖。
- **口诀**：原核"**一（衣原体）支（支原体）细（细菌）篮（蓝细菌）子放（放线菌）**"。带"菌"字的：酵母菌、霉菌、蘑菇是**真菌（真核）**；乳酸菌、大肠杆菌是**细菌（原核）**。

### 第2章 组成细胞的分子
- **大白话**：细胞是由哪些"零件"做成的。
- **必背句**
  1. 大量元素：**C、H、O、N、P、S、K、Ca、Mg**；微量元素：**Fe、Mn、Zn、Cu、B、Mo**（口诀：**铁猛碰新木桶**——Fe Mn B Zn Mo Cu）。
  2. **C 是最基本元素**，生物大分子以**碳链**为骨架。
  3. 细胞中含量最多的化合物是**水**，最多的有机物是**蛋白质**。
  4. 水的两种形式：**自由水**（良好溶剂、参与反应、运输）和**结合水**（细胞结构的组成成分）。**自由水/结合水比值越高，代谢越旺盛，抗逆性越弱**。
  5. 无机盐主要以**离子**形式存在；缺 $\mathbf{Fe^{2+}}$ $\rightarrow$ 血红蛋白合成受阻（贫血）；缺 $\mathbf{Mg^{2+}}$ $\rightarrow$ 叶绿素合成受阻；血钙**过低 $\rightarrow$ 抽搐**。
  6. 糖类是**主要的能源物质**；**脂肪是良好的储能物质**；**ATP 是直接能源物质**。
  7. 多糖：植物有**淀粉、纤维素**，动物有**糖原**，几丁质在甲壳类外壳和真菌细胞壁中；**单体都是葡萄糖**（几丁质除外）。
  8. 脂质包括**脂肪、磷脂（膜的主要成分）、固醇（胆固醇、性激素、维生素 D）**。
  9. 氨基酸结构通式：至少有**一个氨基和一个羧基连在同一个碳原子上**；区别在于 **R 基**。
  10. 蛋白质多样性原因：氨基酸的**种类、数目、排列顺序**不同，以及肽链盘曲折叠形成的**空间结构**不同。
  11. 计算：**肽键数 = 脱去的水分子数 = 氨基酸数 $-$ 肽链数**。
  12. 核酸：DNA（脱氧核糖、ATGC）和 RNA（核糖、AUGC）；核酸是**遗传信息的携带者**；单体是**核苷酸**（一分子磷酸 + 一分子五碳糖 + 一分子含氮碱基）。
  13. 检测：**还原糖 $\rightarrow$ 斐林试剂，水浴加热，砖红色沉淀**；**脂肪 $\rightarrow$ 苏丹Ⅲ，橘黄色**；**蛋白质 $\rightarrow$ 双缩脲试剂，紫色**（先加 A 液 NaOH，再加 B 液 $\mathrm{CuSO_4}$，**不加热**）；淀粉 $\rightarrow$ 碘液变蓝。
- **口诀**：斐林"**现配现用、混合加、要加热**"；双缩脲"**先 A 后 B、不加热**"。

### 第3章 细胞的基本结构
- **必背句**
  1. 细胞膜（细胞质膜）主要由**脂质（磷脂）和蛋白质**组成，还有少量糖类；**磷脂双分子层是基本支架**。
  2. 结构特点：**具有一定的流动性**；功能特性：**选择透过性**。
  3. 细胞膜三大功能：**将细胞与外界环境分隔开、控制物质进出、进行细胞间的信息交流**。
  4. **糖蛋白（糖被）在膜外侧**，与**识别**有关（判断膜内外的依据）。
  5. 细胞器分工：**线粒体——有氧呼吸主要场所**；**叶绿体——光合作用场所**；**核糖体——合成蛋白质**；**内质网——蛋白质加工、脂质合成**；**高尔基体——对蛋白质加工、分类和包装（植物中与细胞壁形成有关）**；**溶酶体——"消化车间"，含多种水解酶**；**液泡——调节渗透压**；**中心体——与有丝分裂有关（动物和低等植物）**。
  6. 双层膜：**线粒体、叶绿体（和细胞核）**；无膜：**核糖体、中心体**。
  7. 含 DNA 的细胞器：**线粒体、叶绿体**；含 RNA 的：再加**核糖体**。
  8. 分泌蛋白合成路线：**核糖体 $\rightarrow$ 内质网 $\rightarrow$ 高尔基体 $\rightarrow$ 细胞膜**（囊泡运输，线粒体供能），研究方法是**同位素标记法（$\mathrm{^{3}H}$ 标记亮氨酸）**。
  9. 细胞核是**遗传信息库**，是**细胞代谢和遗传的控制中心**；核孔实现**核质之间的物质交换和信息交流**；**核仁与某种 RNA 的合成以及核糖体的形成有关**。
- **口诀**：分泌蛋白"**核内高膜，线粒供能**"。

### 第4章 细胞的物质输入和输出
- **必背句**
  1. 渗透作用的条件：**半透膜 + 膜两侧有浓度差**。
  2. 质壁分离：**原生质层**（细胞膜、液泡膜及两层膜之间的细胞质）伸缩性**大于**细胞壁；外界溶液浓度 > 细胞液浓度时失水。
  3. 运输方式：**自由扩散**（不要载体、不耗能，如 $\mathrm{O_2}$、$\mathrm{CO_2}$、甘油、乙醇）；**协助扩散**（要转运蛋白、不耗能，如葡萄糖进红细胞、水通过水通道蛋白）；**主动运输**（要载体蛋白、**消耗能量**、可**逆浓度梯度**）；**胞吞胞吐**（大分子，**依赖膜的流动性**，耗能）。
  4. 转运蛋白分**载体蛋白**（与物质结合、构象改变）和**通道蛋白**（不与物质结合）。
- **口诀**：看"**要不要能量**"分主动被动，看"**要不要蛋白**"分自由协助。

### 第5章 细胞的能量供应和利用
- **必背句（酶）**
  1. 酶是**活细胞产生的具有催化作用的有机物**，绝大多数是**蛋白质**，少数是 **RNA**。
  2. 作用机理：**降低化学反应的活化能**。
  3. 特性：**高效性、专一性、作用条件较温和**。
  4. **高温、过酸、过碱使酶空间结构遭到破坏而永久失活；低温只抑制活性，不破坏结构**。
- **必背句（ATP）**
  1. ATP 结构简式 **A–P~P~P**，A 是**腺苷**（腺嘌呤 + 核糖），~ 是特殊的化学键。
  2. ATP 是**驱动细胞生命活动的直接能源物质**；ATP 与 ADP 的相互转化**时刻不停、处于动态平衡**。
- **必背句（细胞呼吸）**
  1. 有氧呼吸三阶段：**第一阶段 细胞质基质**（葡萄糖 $\rightarrow$ 丙酮酸 + 少量[H] + 少量能量）；**第二阶段 线粒体基质**（丙酮酸 + 水 $\rightarrow \mathrm{CO_2}$ + [H] + 少量能量）；**第三阶段 线粒体内膜**（[H] + $\mathrm{O_2} \rightarrow$ 水 + **大量能量**）。
  2. 总式：$\mathrm{C_6H_{12}O_6 + 6H_2O + 6O_2 \xrightarrow{\text{酶}} 6CO_2 + 12H_2O} + \text{能量}$。
  3. 无氧呼吸**两个阶段都在细胞质基质**，只在第一阶段释放少量能量；产物是**酒精 +** $\mathbf{CO_2}$（酵母菌、多数植物）或**乳酸**（人体肌肉、乳酸菌、马铃薯块茎、甜菜块根）。
  4. 检测：$\mathrm{CO_2}$ 使**澄清石灰水变浑浊**或使**溴麝香草酚蓝溶液由蓝变绿再变黄**；酒精在**酸性条件**下使**橙色的重铬酸钾**变成**灰绿色**。
- **必背句（光合作用）**
  1. 色素分布在**类囊体薄膜**上；提取用**无水乙醇**，分离用**层析液**；滤纸条从上到下：**胡萝卜素（橙黄）、叶黄素（黄）、叶绿素 a（蓝绿）、叶绿素 b（黄绿）**。
  2. 叶绿素主要吸收**红光和蓝紫光**，类胡萝卜素主要吸收**蓝紫光**。
  3. **光反应**在类囊体薄膜：水的光解（产生 $\mathbf{O_2}$ 和 **NADPH**）、合成 **ATP**。
  4. **暗反应**在叶绿体基质：$\mathbf{CO_2}$ **的固定**（$\mathrm{CO_2} + \mathrm{C_5} \rightarrow \mathrm{2C_3}$），$\mathbf{C_3}$ **的还原**（利用 ATP 和 NADPH，生成糖类和 $\mathrm{C_5}$）。
  5. $\mathbf{O_2}$ **中的氧全部来自水**（鲁宾和卡门，同位素标记）。
  6. 突然**停止光照**：$\mathrm{C_3} \uparrow$、$\mathrm{C_5} \downarrow$；突然**停止 $\mathrm{CO_2}$ 供应**：$\mathrm{C_3} \downarrow$、$\mathrm{C_5} \uparrow$。
  7. **净光合速率 = 总光合速率 $-$ 呼吸速率**；"$\mathrm{CO_2}$ 吸收量、$\mathrm{O_2}$ 释放量、有机物积累量"都是**净**。
- **口诀**：色素带"**胡黄 a b，橙黄蓝绿黄绿**"；突变题"**停光 $\mathrm{C_3}$ 升，停碳 $\mathrm{C_3}$ 降**"。

### 第6章 细胞的生命历程
- **必背句**
  1. 细胞周期：**连续分裂的细胞**，从一次分裂完成时开始到下一次分裂完成时为止；**分裂间期**（占 90%~95%）完成 **DNA 复制和有关蛋白质合成**。
  2. 有丝分裂各期：**前期**——核膜核仁消失，出现纺锤体和染色体；**中期**——着丝粒排列在赤道板上（**观察计数最佳时期**）；**后期**——着丝粒分裂，染色体数目加倍；**末期**——核膜核仁重现，纺锤体消失。
  3. 动植物区别：**前期纺锤体形成方式**（植物从两极发出纺锤丝，动物由中心体发出星射线）；**末期细胞质分裂方式**（植物形成**细胞板**，动物**细胞膜向内凹陷缢裂**）。
  4. 观察有丝分裂：**解离（盐酸 + 酒精）$\rightarrow$ 漂洗 $\rightarrow$ 染色（甲紫/醋酸洋红）$\rightarrow$ 制片**；观察的细胞**已经死亡**。
  5. 细胞分化：**基因的选择性表达**，遗传物质**不变**；一般**不可逆**。
  6. 细胞全能性：已分化的细胞仍具有**发育成完整个体或分化成其他各种细胞的潜能和特性**。
  7. **细胞凋亡**是**由基因决定的细胞自动结束生命**的过程（编程性死亡，**对机体有利**）；**细胞坏死**是不利因素导致的**被动**死亡。
  8. 衰老细胞特征：**水分减少、体积变小；多种酶活性降低；色素积累；呼吸速率减慢；细胞核体积增大；膜通透性改变**。
- **口诀**：有丝分裂"**膜仁消失现两体，形数清晰赤道齐，点裂数增均两极，两消两现重开始**"。

## 四、必修2 遗传与进化

![[02-必修2-遗传与进化.png]]

### 第1章 遗传因子的发现（孟德尔定律）
- **必背句**
  1. 豌豆优点：**自花传粉、闭花受粉**，自然状态下一般是**纯种**；有**易于区分的相对性状**。
  2. 假说—演绎法：**观察现象提出问题 $\rightarrow$ 提出假说 $\rightarrow$ 演绎推理（设计测交）$\rightarrow$ 实验验证 $\rightarrow$ 得出结论**。"演绎推理"是**预测测交结果**这一步。
  3. **分离定律**：在生物体细胞中，控制同一性状的遗传因子**成对存在**，不相融合；形成配子时，成对的遗传因子**发生分离**，分别进入不同配子中。
  4. **自由组合定律**：控制不同性状的遗传因子的分离和组合**互不干扰**；形成配子时，决定同一性状的成对遗传因子彼此分离，决定不同性状的遗传因子**自由组合**。
  5. 实质（结合细胞学）：减数分裂Ⅰ后期，**等位基因随同源染色体分开而分离**，**非同源染色体上的非等位基因自由组合**。
  6. 测交：与**隐性纯合子**杂交，用来**测定 $\mathrm{F_1}$ 的基因型（产生配子的种类和比例）**。
- **必背比例**：一对 **3:1**（测交 1:1）；两对 **9:3:3:1**（测交 1:1:1:1）；变式 9:7、9:6:1、15:1、12:3:1、9:3:4、13:3 都是 9:3:3:1 的合并。

### 第2章 基因和染色体的关系
- **必背句**
  1. 减数分裂：**染色体复制一次，细胞连续分裂两次**，结果子细胞染色体数目**减半**。
  2. 减Ⅰ特征：**同源染色体联会形成四分体**、**四分体中非姐妹染色单体可能互换**、**同源染色体分离**；减Ⅰ结束时染色体数目减半。
  3. 减Ⅱ特征：**着丝粒分裂，姐妹染色单体分开**（与有丝分裂类似，但**无同源染色体**）。
  4. 精子形成**细胞质均等分裂**，卵细胞形成**两次不均等分裂**（初级卵母细胞、次级卵母细胞不均等），1 个卵原细胞只得 **1 个卵细胞**。
  5. 萨顿用**类比推理法**提出"基因在染色体上"；摩尔根用**假说—演绎法**（果蝇白眼）证明。
  6. 基因在染色体上呈**线性排列**。
  7. 伴 X 隐性（红绿色盲、血友病）：**男性患者多于女性**；**女患者的父亲和儿子一定患病**；**隔代交叉遗传**。
  8. 伴 X 显性（抗维生素 D 佝偻病）：**女性患者多于男性**；**男患者的母亲和女儿一定患病**。
  9. 伴 Y：**只传男不传女**。
- **口诀（判遗传病）**："**无中生有为隐性，隐性遗传看女病，父子都病可能伴性，父子有正非伴性；有中生无为显性，显性遗传看男病，母女都病可能伴性，母女有正非伴性**"。

### 第3章 基因的本质
- **必背句**
  1. 格里菲思：**加热致死的 S 型菌中存在"转化因子"**；艾弗里：**DNA 才是使 R 型菌产生稳定遗传变化的物质**（减法原理）。
  2. 赫尔希和蔡斯：用 $\mathbf{^{35}S}$ **标记蛋白质、$\mathrm{^{32}P}$ 标记 DNA** 的 T2 噬菌体侵染大肠杆菌，证明 **DNA 是遗传物质**。
  3. $\mathbf{^{35}S}$ **组上清液放射性高；$\mathrm{^{32}P}$ 组沉淀物放射性高**。$\mathrm{^{32}P}$ 组上清液有放射性：**保温时间过短（未侵入）或过长（子代释放）**。
  4. **DNA 是主要的遗传物质**（因为绝大多数生物以 DNA 为遗传物质，少数病毒是 RNA）。
  5. DNA 双螺旋结构（沃森和克里克）：两条链**反向平行**；**脱氧核糖和磷酸交替连接排在外侧构成基本骨架**，碱基在内侧；碱基互补配对 **A–T、G–C**，以**氢键**相连（G–C 三个氢键更稳定）。
  6. DNA 复制：**半保留复制**；**边解旋边复制**；需要**模板、原料（4 种脱氧核苷酸）、能量、酶（解旋酶、DNA 聚合酶）**；主要在**细胞核**，时间是**有丝分裂间期和减Ⅰ前的间期**。
  7. 基因通常是**有遗传效应的 DNA 片段**（RNA 病毒是 RNA 片段）。
- **必背计算**：双链中 **A = T、G = C，嘌呤 = 嘧啶 = 50%**；一个 DNA 复制 n 次得 $\boldsymbol{2^n}$ **个 DNA**，含母链的 **2 个**。

### 第4章 基因的表达
- **必背句**
  1. **转录**：在**细胞核**中，以 DNA 的**一条链**为模板，按碱基互补配对合成 **RNA**，需要 **RNA 聚合酶**。
  2. **翻译**：在**核糖体**上，以 **mRNA** 为模板合成具有一定氨基酸顺序的**蛋白质**；**tRNA 运载氨基酸**，一端有**反密码子**。
  3. **密码子**：mRNA 上决定一个氨基酸的**3 个相邻碱基**；共 64 种，**终止密码子一般不编码氨基酸**；一种氨基酸可对应多种密码子（**简并性**）。
  4. 中心法则：DNA $\rightarrow$ DNA（复制）、DNA $\rightarrow$ RNA（转录）、RNA $\rightarrow$ 蛋白质（翻译）；补充：**RNA 复制、逆转录**。
  5. 基因控制性状两条途径：**通过控制酶的合成来控制代谢过程，进而间接控制性状**（白化病、豌豆皱粒）；**通过控制蛋白质的结构直接控制性状**（镰状细胞贫血、囊性纤维化）。
  6. **表观遗传**：生物体**基因的碱基序列保持不变**，但**基因表达和表型发生可遗传变化**（如 DNA 甲基化、组蛋白修饰）。
- **口诀**：转录"**核里 DNA 一条链，RNA 聚合酶来连**"；翻译"**核糖体上读 mRNA，tRNA 搬氨基酸**"。

### 第5章 基因突变及其他变异
- **必背句**
  1. 基因突变：DNA 分子中发生**碱基的替换、增添或缺失**，而引起的**基因碱基序列的改变**。
  2. 特点：**普遍性、随机性、不定向性、低频性**；多数有害。基因突变是**产生新基因的途径**，是**生物变异的根本来源**。
  3. 基因重组：**减Ⅰ前期同源染色体非姐妹染色单体互换**、**减Ⅰ后期非同源染色体自由组合**；**不产生新基因，产生新基因型**。
  4. 染色体变异：结构变异（**缺失、重复、易位、倒位**）和数目变异（个别增减、**以染色体组成倍增减**）。
  5. 单倍体：**体细胞中染色体数目与本物种配子染色体数目相同**的个体（不论有几个染色体组）。
  6. 秋水仙素（或低温）作用：**抑制纺锤体形成**，使染色体数目加倍。
  7. 育种对照：杂交育种（基因重组）、诱变育种（基因突变）、单倍体育种（染色体变异，**明显缩短育种年限**）、多倍体育种（染色体变异，如**三倍体无子西瓜**）、基因工程育种（基因重组）。

### 第6章 生物的进化
- **必背句**
  1. **化石**是研究生物进化最直接、最重要的证据。
  2. 现代生物进化理论：**种群是生物进化的基本单位**；**突变和基因重组产生进化的原材料**；**自然选择决定生物进化的方向**；**隔离是物种形成的必要条件**。
  3. **生物进化的实质是种群基因频率的定向改变**。
  4. **新物种形成的标志是生殖隔离**的出现（不一定经过地理隔离，如多倍体）。
  5. **协同进化**：不同物种之间、生物与无机环境之间在相互影响中不断进化和发展；结果形成**生物多样性**（遗传多样性、物种多样性、生态系统多样性）。
- **必背计算**：基因频率 = 某基因数 $\div$ 全部等位基因数；遗传平衡时 $\boldsymbol{p^2 + 2pq + q^2 = 1}$。

## 五、选择性必修1 稳态与调节

![[03-选必1-稳态与调节.png]]

### 第1章 人体的内环境与稳态
- **必背句**
  1. 内环境 = **细胞外液** = **血浆 + 组织液 + 淋巴液**。
  2. 关系：**血浆 $\rightleftharpoons$ 组织液 $\rightarrow$ 淋巴液 $\rightarrow$ 血浆**（组织液和血浆双向，淋巴单向）。
  3. 内环境理化性质：**渗透压、酸碱度、温度**；血浆渗透压主要与**无机盐和蛋白质**含量有关；血浆 pH **7.35~7.45**，靠 $\mathbf{HCO_3^{-}}$ **、** $\mathbf{H_2CO_3}$ 等缓冲物质维持。
  4. **稳态的调节机制：神经—体液—免疫调节网络**。
  5. 组织水肿原因：**血浆蛋白减少（营养不良、肾小球肾炎）、淋巴回流受阻、毛细血管通透性增大（过敏）、局部代谢旺盛**。
  6. 不属于内环境的成分：**血红蛋白、呼吸酶、载体蛋白、消化液**等（在细胞内或与外界相通）。

### 第2章 神经调节
- **必背句**
  1. 神经调节的基本方式是**反射**，结构基础是**反射弧**：**感受器 $\rightarrow$ 传入神经 $\rightarrow$ 神经中枢 $\rightarrow$ 传出神经 $\rightarrow$ 效应器**（效应器 = 传出神经末梢 + 它支配的肌肉或腺体）。
  2. 静息电位**外正内负**，由 $\mathbf{K^{+}}$ **外流**形成；动作电位**外负内正**，由 $\mathbf{Na^{+}}$ **内流**形成（都是协助扩散）。
  3. 兴奋在神经纤维上**双向传导**；在神经元之间**单向传递**——因为**神经递质只存在于突触小泡中，只能由突触前膜释放，作用于突触后膜**。
  4. 突触结构：**突触前膜、突触间隙、突触后膜**；信号转换：**电信号 $\rightarrow$ 化学信号 $\rightarrow$ 电信号**。
  5. 分级调节：**低级中枢受脑中相应高级中枢的调控**（如排尿）。
  6. 大脑言语区：**W 区（写）、V 区（看）、S 区（说）、H 区（听）**受损分别"不能写、看不懂、不能说、听不懂"。
  7. 自主神经系统：**交感神经**（兴奋状态，心跳加快、胃肠蠕动减弱）和**副交感神经**（安静状态）作用通常**相反**。

### 第3章 体液调节
- **必背句**
  1. 激素调节特点：**通过体液运输；作用于靶器官、靶细胞；作为信使传递信息；微量和高效**；激素**一经靶细胞接受并起作用后就失活**。
  2. 血糖平衡：**胰岛素（胰岛 B 细胞）是唯一降血糖的激素**；**胰高血糖素（胰岛 A 细胞）、肾上腺素**等升血糖。
  3. 分级调节：**下丘脑 $\rightarrow$ 促××激素释放激素 $\rightarrow$ 垂体 $\rightarrow$ 促××激素 $\rightarrow$ 腺体 $\rightarrow$ 激素**（甲状腺、性腺、肾上腺皮质）。
  4. 反馈调节：甲状腺激素过多时**抑制下丘脑和垂体**的分泌（**负反馈**）。
  5. 体温调节中枢在**下丘脑**；寒冷时**甲状腺激素、肾上腺素**分泌增加、皮肤血管收缩、骨骼肌战栗。
  6. 水盐平衡：细胞外液渗透压升高 $\rightarrow$ 下丘脑渗透压感受器 $\rightarrow$ **下丘脑合成、垂体释放抗利尿激素** $\rightarrow$ **肾小管和集合管重吸收水增加**；**渴觉在大脑皮层**产生。
  7. 神经调节与体液调节比较：神经调节**迅速、准确、范围局限、时间短暂**；体液调节**较缓慢、范围广、时间较长**。

### 第4章 免疫调节
- **必背句**
  1. 三道防线：**皮肤和黏膜（第一道）**；**体液中的杀菌物质和吞噬细胞（第二道）**——前两道是**非特异性免疫**；**第三道是特异性免疫（体液免疫和细胞免疫）**。
  2. 免疫系统三大功能：**免疫防御、免疫自稳、免疫监视**。
  3. 体液免疫：B 细胞活化需要**两个信号**——**病原体与 B 细胞接触**、**辅助性 T 细胞表面特定分子发生变化并与 B 细胞结合**；还需要**细胞因子**促进；B 细胞增殖分化为**浆细胞（产生抗体）和记忆 B 细胞**。
  4. 细胞免疫：**细胞毒性 T 细胞**识别、接触、裂解**被病原体感染的靶细胞**；细胞因子能加速这一过程。
  5. **浆细胞是唯一不能识别抗原的免疫细胞**；**唯一能产生抗体的细胞**。
  6. 二次免疫：**记忆细胞迅速增殖分化**，反应**更快、更强**。
  7. 免疫失调：**过敏反应**（再次接触过敏原）、**自身免疫病**（类风湿关节炎、系统性红斑狼疮）、**免疫缺陷病**（艾滋病：HIV 主要攻击**辅助性 T 细胞**）。

### 第5章 植物生命活动的调节
- **必背句**
  1. 生长素发现：达尔文（**胚芽鞘尖端受单侧光刺激后向下面伸长区传递某种"影响"**）$\rightarrow$ 鲍森·詹森（影响可透过琼脂片）$\rightarrow$ 拜尔（影响分布不均匀造成弯曲）$\rightarrow$ 温特（命名为**生长素**）。
  2. 生长素的运输：**极性运输**（从形态学上端到形态学下端，是**主动运输**）；单侧光使生长素在尖端**横向运输**到背光侧。
  3. 生长素作用特点：**低浓度促进生长，高浓度抑制生长**（体现于**顶端优势、根的向地性**；**茎的背地性和向光性不体现**高浓度抑制）。
  4. 敏感程度：**根 > 芽 > 茎**；**双子叶植物 > 单子叶植物**（用于除去单子叶作物田中的双子叶杂草）。
  5. 其他激素：**赤霉素**——促进细胞伸长、种子萌发和果实发育；**细胞分裂素**——促进细胞分裂；**脱落酸**——抑制细胞分裂、促进气孔关闭、维持种子休眠；**乙烯**——**促进果实成熟**。
  6. 植物生长发育的调控是**基因表达调控、激素调节和环境因素调节**共同完成的；光敏色素接受光信号。

## 六、选择性必修2 生物与环境

![[04-选必2-生物与环境.png]]

### 第1章 种群及其动态
- **必背句**
  1. **种群密度是种群最基本的数量特征**；出生率和死亡率、迁入率和迁出率**直接决定**种群密度；**年龄结构预测**变化趋势；性别比例影响出生率。
  2. 调查方法：植物和活动能力弱的动物用**样方法**（随机取样）；活动能力强、范围大的动物用**标记重捕法**：**N = 第一次标记数 $\times$ 第二次捕获数 $\div$ 第二次捕获中被标记数**。
  3. **"J"形增长**：$N_t = N_0\lambda^t$，条件是**食物和空间充裕、气候适宜、没有天敌和其他竞争物种**。
  4. **"S"形增长**：存在环境容纳量 **K 值**；**K/2 时增长速率最大**。
  5. 应用：**害虫防治要在 K/2 之前**，并设法降低 K 值；**渔业捕捞后剩余量维持在 K/2**。
  6. 影响因素：**密度制约因素**（食物、天敌、传染病）和**非密度制约因素**（气温、干旱等气候因素）。

### 第2章 群落及其演替
- **必背句**
  1. **物种组成是区别不同群落的重要特征**；丰富度是群落中**物种数目的多少**。
  2. 种间关系：**原始合作、互利共生、捕食、寄生、种间竞争**。
  3. 群落空间结构：**垂直结构**（分层现象；植物与**光照**有关，动物与**栖息空间和食物条件**有关）和**水平结构**（镶嵌分布）。
  4. 生态位：一个物种在群落中的**地位或作用**，包括所处的**空间位置、占用资源的情况、与其他物种的关系**等。
  5. **初生演替**（从未被植物覆盖或植被被彻底消灭的地方开始，如沙丘、火山岩、冰川泥）和**次生演替**（保留了原有土壤条件和繁殖体，如弃耕农田、火灾后的森林）。
  6. **人类活动会使群落演替按照不同于自然演替的速度和方向进行**。
  7. 土壤小动物丰富度调查用**取样器取样法**；统计方法有**记名计算法和目测估计法**。

### 第3章 生态系统及其稳定性
- **必背句**
  1. 生态系统结构 = **组成成分（非生物的物质和能量、生产者、消费者、分解者）+ 营养结构（食物链和食物网）**。
  2. **生产者是生态系统的基石**；分解者将有机物分解成无机物。
  3. 能量流动：**起点是生产者固定的太阳能**；特点是**单向流动、逐级递减**；相邻营养级传递效率约 **10%~20%**。
  4. 某营养级同化量的去向：**呼吸作用散失 + 用于生长、发育和繁殖**（后者 = 流向下一营养级 + 流向分解者 + 未利用）。
  5. **摄入量 = 同化量 + 粪便量**；**粪便中的能量属于上一营养级**。
  6. 物质循环：**全球性、循环往复**；碳在生物群落与非生物环境之间以 $\mathbf{CO_2}$ 形式循环，在生物群落内部以**含碳有机物**形式传递。
  7. **生物富集**：有害物质沿食物链**在营养级越高的生物体内浓度越高**。
  8. 信息种类：**物理信息、化学信息、行为信息**；作用：**生命活动的正常进行、生物种群的繁衍离不开信息传递；能调节生物的种间关系，维持生态系统的平衡与稳定**。
  9. 能量流动、物质循环、信息传递三者关系：**物质是能量的载体，能量是物质循环的动力，信息传递决定能量流动和物质循环的方向和状态**。
  10. 稳定性基础：**自我调节能力**，基础是**负反馈调节**；**抵抗力稳定性**（组分越多、营养结构越复杂越高）和**恢复力稳定性**一般相反。
- **口诀**：能量"**单向、递减、10%~20%**"；物质"**全球、循环**"；信息"**双向**"。

### 第4章 人与环境
- **必背句**
  1. **生态足迹**越大，代表人类所需资源越多，对生态和环境的影响越大。
  2. 全球性生态环境问题：**全球气候变化、水资源短缺、臭氧层破坏、土地荒漠化、生物多样性丧失、环境污染**。
  3. 生物多样性价值：**直接价值**（食用、药用、科研、旅游、文学艺术）、**间接价值**（生态功能，**明显大于直接价值**）、**潜在价值**。
  4. 保护生物多样性最有效的措施：**就地保护（建立自然保护区）**；**易地保护**（植物园、动物园、濒危动植物繁育中心）。
  5. 生态工程原理：**自生、循环、协调、整体**。

## 七、选择性必修3 生物技术与工程

![[05-选必3-生物技术与工程.png]]

### 第1章 发酵工程
- **必背句**
  1. 果酒：**酵母菌**，先通气后密封，温度 **18~** $30\,^{\circ}\mathbf{C}$；果醋：**醋酸菌（好氧）**，**一直通气**，温度 **30~** $35\,^{\circ}\mathbf{C}$；泡菜：**乳酸菌（厌氧）**，坛口水封；腐乳：主要是**毛霉**。
  2. 培养基一般含**水、碳源、氮源、无机盐**；**选择培养基**允许特定微生物生长、抑制其他微生物（如以尿素为唯一氮源分离尿素分解菌）。
  3. 灭菌与消毒：**灭菌杀死所有微生物（包括芽孢和孢子）**；培养基用**湿热灭菌（高压蒸汽）**，接种环用**灼烧灭菌**，玻璃器皿可用**干热灭菌**。
  4. 纯化接种：**平板划线法**（不能计数）和**稀释涂布平板法**（可以计数，计数结果往往**偏小**，因为两个或多个细胞连在一起时只长出一个菌落）；选菌落数 **30~300** 的平板计数。
  5. 发酵工程的中心环节是**发酵罐内发酵**；要随时检测并控制**温度、pH、溶解氧**等。

### 第2章 细胞工程
- **必背句**
  1. 植物组织培养原理：**植物细胞的全能性**；过程：**外植体 $\rightarrow$（脱分化）$\rightarrow$ 愈伤组织 $\rightarrow$（再分化）$\rightarrow$ 试管苗**；**生长素与细胞分裂素的比例**影响分化方向（比值高利于生根，比值低利于生芽）。
  2. 植物体细胞杂交：先用**纤维素酶和果胶酶**去除细胞壁得到原生质体，再诱导融合（PEG、电融合），**杂种细胞再生出细胞壁是融合完成的标志**；意义是**打破生殖隔离，实现远缘杂交育种**。
  3. 动物细胞培养：用**胰蛋白酶或胶原蛋白酶**处理分散细胞；气体环境 **95% 空气 + 5%** $\mathbf{CO_2}$（$\mathrm{CO_2}$ 维持培养液 pH）；有**接触抑制**现象。
  4. 单克隆抗体：**B 淋巴细胞 + 骨髓瘤细胞**融合（可用**灭活病毒**诱导）$\rightarrow$ 用**选择培养基**筛选出杂交瘤细胞 $\rightarrow$ **克隆化培养和抗体检测**筛选出能产生所需抗体的杂交瘤细胞；特点**特异性强、灵敏度高、可大量制备**。
  5. 核移植克隆动物体现**动物细胞核的全能性**。
  6. 胚胎工程：**体外受精**（精子需**获能**，卵母细胞培养到 **MⅡ 期**）$\rightarrow$ 早期胚胎培养 $\rightarrow$ **胚胎移植**（受体与供体**同期发情**处理；受体对外来胚胎基本**不发生免疫排斥**）；**胚胎分割**选择**桑葚胚或囊胚**，分割囊胚时要**将内细胞团均等分割**。

### 第3章 基因工程
- **必背句**
  1. 三种工具：**限制酶**（识别特定核苷酸序列并在特定位点切割磷酸二酯键）、**DNA 连接酶**（连接磷酸二酯键）、**载体**（质粒最常用；要有**复制原点、标记基因、限制酶切割位点**）。
  2. 四个步骤：**目的基因的筛选与获取 $\rightarrow$ 基因表达载体的构建（核心步骤）$\rightarrow$ 将目的基因导入受体细胞 $\rightarrow$ 目的基因的检测与鉴定**。
  3. 表达载体组成：**启动子（RNA 聚合酶识别和结合的部位）+ 目的基因 + 终止子 + 标记基因 + 复制原点**。
  4. 导入方法：植物——**农杆菌转化法**（利用 Ti 质粒的 **T-DNA** 可转移并整合到染色体 DNA 上）、花粉管通道法；动物——**显微注射法**（受精卵）；微生物——$\mathbf{Ca^{2+}}$ **处理**使其处于易吸收 DNA 的状态。
  5. 检测鉴定：是否插入/转录——**PCR**；是否翻译——**抗原—抗体杂交**；个体水平——**抗虫、抗病接种实验**。
  6. **PCR** 原理是 **DNA 半保留复制**；每轮循环：**变性（$90\,^{\circ}\mathrm{C}$以上）$\rightarrow$ 复性（$50\,^{\circ}\mathrm{C}$左右，引物结合）$\rightarrow$ 延伸（$72\,^{\circ}\mathrm{C}$左右，耐高温的 DNA 聚合酶）**；需要**模板、引物（2 种）、4 种脱氧核苷酸、耐高温 DNA 聚合酶、** $\mathbf{Mg^{2+}}$；**DNA 聚合酶只能从引物的 3′ 端延伸子链**（子链 5′ $\rightarrow$ 3′）。
  7. 产物鉴定：**琼脂糖凝胶电泳**。
  8. **DNA 粗提取**：利用 DNA **不溶于酒精**而某些蛋白质溶于酒精（加**预冷的 95% 酒精**析出白色丝状物）；DNA 在 2 mol/L NaCl 中溶解；鉴定用**二苯胺试剂沸水浴变蓝**。
  9. **蛋白质工程**：从**预期的蛋白质功能**出发 $\rightarrow$ 设计预期的蛋白质结构 $\rightarrow$ 推测应有的氨基酸序列 $\rightarrow$ 找到相对应的脱氧核苷酸序列（基因）；本质是**改造基因**。
- **口诀**：PCR "**变性解旋、复性引物、延伸合成**"；表达载体"**启目终标复**"。

### 第4章 生物技术的安全性与伦理问题
- **必背句**
  1. 我国对转基因产品实行**标识制度**。
  2. 我国**禁止生殖性克隆人**，**不反对治疗性克隆**（"四不原则"：不赞成、不允许、不支持、不接受任何生殖性克隆人实验）。
  3. 我国**在任何情况下不发展、不生产、不储存生物武器**，并反对其扩散。

## 八、实验专题必背（江苏卷几乎每年都有实验题）

| 实验 | 试剂 / 方法 | 现象 / 关键 |
|---|---|---|
| 还原糖检测 | 斐林试剂，50~$65\,^{\circ}\mathrm{C}$ 水浴 | 砖红色沉淀 |
| 脂肪检测 | 苏丹Ⅲ，体积分数 50% 酒精洗去浮色 | 橘黄色 |
| 蛋白质检测 | 双缩脲，先 A 后 B，不加热 | 紫色 |
| 观察叶绿体和细胞质流动 | 黑藻叶片 | 以叶绿体运动为标志 |
| 质壁分离与复原 | 紫色洋葱鳞片叶外表皮，0.3 g/mL 蔗糖 | 液泡变小、颜色变深 |
| 色素提取分离 | 无水乙醇、$\mathrm{SiO_2}$（研磨充分）、$\mathrm{CaCO_3}$（防止色素被破坏）、层析液 | 4 条色素带 |
| 探究酵母菌呼吸方式 | 澄清石灰水 / 溴麝香草酚蓝；酸性重铬酸钾 | 灰绿色说明有酒精 |
| 观察有丝分裂 | 根尖分生区，解离$\rightarrow$漂洗$\rightarrow$染色$\rightarrow$制片 | 大部分细胞处于间期 |
| 低温诱导染色体加倍 | $4\,^{\circ}\mathrm{C}$ 低温，卡诺氏液固定 | 抑制纺锤体形成 |
| 培养液中酵母菌计数 | 血细胞计数板，先盖盖玻片后滴培养液 | 计数前振荡试管 |
| 土壤小动物丰富度 | 取样器取样，诱虫器（避光、避高温） | 记名计算法 / 目测估计法 |
| DNA 粗提取与鉴定 | 预冷 95% 酒精；二苯胺沸水浴 | 白色丝状物；变蓝 |

**实验设计万能句**：遵循**单一变量原则、对照原则、平行重复原则**；自变量是"我改变的"，因变量是"我测量的"，其余都是**无关变量（要相同且适宜）**。
