## 0. 先搞懂这五个「零件」（前置知识）

| 零件 | 大白话 | 必背 |
|---|---|---|
| **ATP** | 细胞里的「现金」，能直接花的能量 | ATP 是**直接能源物质**；结构简式 **A-P~P~P**；ATP ⇌ ADP + Pi + 能量 |
| **酶** | 让反应快起来的「工人」 | 每一步反应都要酶，所以**温度、pH 影响酶 → 影响光合和呼吸** |
| **NADH**（呼吸里的 [H]） | 呼吸作用里的「电子搬运车」 | 呼吸产生的 [H] 是 **NADH（还原型辅酶Ⅰ）** |
| **NADPH**（光合里的 [H]） | 光合作用里的「电子搬运车」 | 光反应产生的是 **NADPH（还原型辅酶Ⅱ）**，**既作还原剂，又储存部分能量** |
| **线粒体 / 叶绿体** | 呼吸的「发电厂」/ 光合的「食品厂」 | 线粒体：外膜、**内膜（向内折叠成嵴）**、**基质**；叶绿体：外膜、内膜、**类囊体（堆叠成基粒）**、**基质** |

> ⚠ 易错：**呼吸的 [H] ≠ 光合的 [H]**，一个是 NADH，一个是 NADPH，不能混用。

## 第一部分 细胞呼吸

### 1.1 什么是细胞呼吸

**细胞呼吸**：有机物在细胞内经过一系列**氧化分解**，生成 CO₂ 或其他产物，**释放能量并生成 ATP** 的过程。

> 大白话：把葡萄糖「烧掉」换成 ATP，不过是用酶一点点慢慢烧，不着火。
> ⚠ 「呼吸作用」不是「呼吸运动」（人用肺吸气呼气是呼吸运动）。

分两类：**有氧呼吸**（主要方式）和**无氧呼吸**。

### 1.2 有氧呼吸——三个阶段（最高频）

| 阶段 | 场所 | 反应物 | 产物 | 能量 |
|---|---|---|---|---|
| 第一阶段 | **细胞质基质** | 1 葡萄糖 | **2 丙酮酸 + 少量 [H]** | **少量**能量 |
| 第二阶段 | **线粒体基质** | 2 丙酮酸 + **6 H₂O** | **6 CO₂ + 大量 [H]** | **少量**能量 |
| 第三阶段 | **线粒体内膜** | 前两阶段的 [H] + **6 O₂** | **12 H₂O** | **大量**能量 |

**总反应式（必背，会默写）：**

C₆H₁₂O₆ + 6H₂O + 6O₂ —酶→ 6CO₂ + 12H₂O + 能量

**口诀：一糖变两酸（质基质），二酸加水出 CO₂（基质），三阶段氢和氧合成水（内膜），能量最多在第三。**

**必背句：**
- 有氧呼吸**第一阶段与无氧呼吸第一阶段完全相同**。
- **O₂ 只参与第三阶段**；**H₂O 在第二阶段参与、第三阶段生成**；**CO₂ 在第二阶段产生**。
- **葡萄糖不能进入线粒体**，进入线粒体的是**丙酮酸**。
- 有氧呼吸释放的能量**大部分以热能形式散失**，少部分储存在 ATP 中（热能用于维持体温）。

**元素追踪（选择题最爱）：**
- 葡萄糖中的 O → 进入 **CO₂**
- O₂ 中的 O（¹⁸O₂）→ 进入 **H₂O**（第三阶段）；这个水再参与第二阶段 → 后来 CO₂ 里也会出现 ¹⁸O
- 反应物 H₂O 中的 O → 进入 **CO₂**

### 1.3 无氧呼吸——两种类型

| | 酒精发酵 | 乳酸发酵 |
|---|---|---|
| 场所 | **全在细胞质基质** | **全在细胞质基质** |
| 反应式 | C₆H₁₂O₆ —酶→ **2C₂H₅OH + 2CO₂** + 少量能量 | C₆H₁₂O₆ —酶→ **2C₃H₆O₃（乳酸）** + 少量能量 |
| 生物举例 | **酵母菌、大多数植物**（如水淹的根） | **乳酸菌、人和动物的骨骼肌、马铃薯块茎、甜菜块根、玉米胚** |
| 有没有 CO₂ | 有 | **没有** |

**必背句：**
- 无氧呼吸**只在第一阶段释放少量能量、生成少量 ATP**；**第二阶段不释放能量**（[H] 把丙酮酸还原成酒精或乳酸）。
- 无氧呼吸中，葡萄糖里的能量**大部分储存在酒精或乳酸中**没被释放。
- 产物不同的**根本原因**：**酶不同**；**直接原因**是不同生物含有的酶的种类不同（由基因决定）。
- 人剧烈运动时：**骨骼肌无氧呼吸产生乳酸**，**人体产生的 CO₂ 只来自有氧呼吸（线粒体基质）**。

> ⚠ 易错：「人体细胞呼吸 CO₂ 释放量 = O₂ 吸收量」（以葡萄糖为底物时），因为人的无氧呼吸不产 CO₂。

### 1.4 有氧呼吸 vs 无氧呼吸

| 比较 | 有氧呼吸 | 无氧呼吸 |
|---|---|---|
| 场所 | 细胞质基质 + **线粒体** | **只有细胞质基质** |
| 要不要 O₂ | 要 | 不要（O₂ 会**抑制**无氧呼吸） |
| 分解程度 | **彻底**分解为 CO₂、H₂O | **不彻底**，产物还有能量（酒精/乳酸） |
| 释放能量 | **大量** | **少量** |
| 共同点 | **第一阶段相同**；都要酶；**实质都是分解有机物、释放能量、生成 ATP** | |

> 拓展：**原核生物没有线粒体**，但有的（如蓝细菌、硝化细菌）也能进行有氧呼吸，相关酶在**细胞质和细胞膜**上。

### 1.5 怎么判断细胞在进行哪种呼吸（以葡萄糖为底物）

| 观察到 | 结论 |
|---|---|
| 不吸收 O₂，只放出 CO₂ | 只进行**酒精发酵** |
| 不吸 O₂ 也不放 CO₂ | 只进行**乳酸发酵**（或细胞已死亡） |
| CO₂ 释放量 **=** O₂ 吸收量 | 只进行**有氧呼吸**（或有氧呼吸 + 乳酸发酵） |
| CO₂ 释放量 **>** O₂ 吸收量 | **有氧呼吸 + 酒精发酵**同时进行 |
| 有 H₂O 生成 | 一定有**有氧呼吸** |

**计算模板（两个比例要背）：**
- 有氧：葡萄糖 : O₂ : CO₂ = **1 : 6 : 6**
- 酒精发酵：葡萄糖 : CO₂ : 酒精 = **1 : 2 : 2**

**例 1** 酵母菌吸收 O₂ 6 mol，释放 CO₂ 10 mol。求有氧、无氧各消耗多少葡萄糖。

1. 先算有氧呼吸——因为 **O₂ 只被有氧呼吸用**，所以从 O₂ 入手。
   有氧消耗葡萄糖 = O₂ ÷ 6，代入：6 ÷ 6 = **1 mol**；有氧产生 CO₂ = 6 × 1 = 6 mol。
2. 剩下的 CO₂ 是无氧呼吸放的：
   无氧 CO₂ = 总 CO₂ − 有氧 CO₂，代入：10 − 6 = 4 mol。
3. 无氧消耗葡萄糖 = 无氧 CO₂ ÷ 2，代入：4 ÷ 2 = **2 mol**。

结论：有氧 1 mol，无氧 2 mol，**无氧消耗的葡萄糖是有氧的 2 倍**。

### 1.6 影响细胞呼吸的因素和应用

| 因素 | 怎么影响 | 应用（答题常用） |
|---|---|---|
| **温度** | 影响**酶活性**；先升后降 | **低温储存**水果蔬菜（**零上低温**，不能冻伤）；大棚夜间**适当降温**减少有机物消耗 |
| **O₂ 浓度** | O₂ 越多有氧越强、无氧越被抑制；**CO₂ 释放总量最低点**对应的 O₂ 浓度（约 5%）**有机物消耗最少** | 果蔬**低氧**储存；**中耕松土**促进根有氧呼吸，利于**吸收无机盐**；稻田定期排水，防止根**无氧呼吸产生酒精烂根** |
| **水** | 自由水多，代谢旺 | 种子**晒干**储存（降低自由水，减弱呼吸） |
| **CO₂** | CO₂ 多抑制呼吸 | 适当提高 CO₂ 储存果蔬 |

**其他常考应用：**
- 包扎伤口用**透气的纱布**：抑制**破伤风芽孢杆菌**等厌氧菌繁殖。
- 提倡**慢跑等有氧运动**：避免肌细胞无氧呼吸产生大量**乳酸**，引起肌肉酸胀乏力。
- 酿酒：**先通气后密封**（先通气让酵母菌有氧呼吸大量繁殖，再密封进行酒精发酵）。
- **储存条件：果蔬 = 零上低温 + 低氧 + 一定湿度；种子 = 低温 + 低氧 + 干燥**。

**答题模板（为什么低温/低氧利于储存）：** 低温降低**呼吸酶的活性**／低氧使**有氧呼吸较弱且无氧呼吸受抑制**，**细胞呼吸减弱，有机物消耗减少**。

### 1.7 实验：探究酵母菌细胞呼吸的方式

| 项目 | 内容 |
|---|---|
| 为什么用酵母菌 | 单细胞真菌，**兼性厌氧**（有氧、无氧都能活） |
| 有氧装置 | 先通过 **NaOH 溶液**（**吸收空气中的 CO₂**，排除干扰）→ 酵母菌培养液 → 澄清石灰水 |
| 无氧装置 | 酵母菌瓶**封口放置一段时间**再连通石灰水（**耗尽瓶中原有的 O₂**） |
| 检测 CO₂ | **澄清石灰水变混浊**；或 **溴麝香草酚蓝溶液：蓝 → 绿 → 黄**（看变黄的时间长短判断 CO₂ 多少） |
| 检测酒精 | **橙色的酸性重铬酸钾溶液 → 灰绿色** |
| 结果 | 两组都产生 CO₂，有氧组**更多更快**；只有无氧组产生酒精 |
| 实验类型 | **对比实验**（两组都是实验组，没有空白对照） |

> ⚠ 易错：**葡萄糖也能让酸性重铬酸钾变色**，所以检测酒精前要**适当延长培养时间，耗尽葡萄糖**。

## 第二部分 光合作用

### 2.1 什么是光合作用

**光合作用**：绿色植物通过**叶绿体**，利用**光能**，把 **CO₂ 和 H₂O** 转化成储存着能量的**有机物**，并释放 **O₂** 的过程。

**总反应式（必背）：**

CO₂ + H₂O —光能、叶绿体→ (CH₂O) + O₂

（用葡萄糖写：6CO₂ + 12H₂O —光能、叶绿体→ C₆H₁₂O₆ + 6O₂ + 6H₂O）

### 2.2 捕获光能的色素

| 色素 | 颜色 | 含量 | 主要吸收 |
|---|---|---|---|
| **胡萝卜素** | **橙黄色** | 最少 | **蓝紫光** |
| **叶黄素** | **黄色** | | **蓝紫光** |
| **叶绿素 a** | **蓝绿色** | **最多** | **红光和蓝紫光** |
| **叶绿素 b** | **黄绿色** | | **红光和蓝紫光** |

- 叶绿素 ≈ 3/4，类胡萝卜素（胡萝卜素 + 叶黄素）≈ 1/4。
- 色素分布在**类囊体薄膜**上（不是叶绿体基质！）。
- 叶片呈绿色：叶绿素**对绿光吸收最少**，绿光被反射。
- 叶绿素合成需要**光、适宜温度、Mg（和 N）**；秋天变黄：**低温使叶绿素分解，类胡萝卜素显现**。
- 大棚用**无色透明**塑料膜最好（透过全部光）；补光用**红光或蓝紫光**。

### 2.3 实验：绿叶中色素的提取和分离（实验题高频）

| 材料/操作 | 作用（答题原句） |
|---|---|
| **无水乙醇** | **溶解（提取）色素**（色素溶于有机溶剂） |
| **二氧化硅（SiO₂）** | 使**研磨充分** |
| **碳酸钙（CaCO₃）** | **防止研磨中色素被破坏** |
| **层析液** | **分离色素**：不同色素在层析液中**溶解度不同**，溶解度高的随层析液在滤纸上**扩散得快** |
| 单层尼龙布过滤 | 不用滤纸，因为滤纸会**吸附色素** |
| 滤液细线 **细、直、齐**，干后**重复画 2～3 次** | 色素带整齐、色素量多 |
| **滤液细线不能触及层析液** | 否则**色素溶解到层析液中**，滤纸条上没有色素带 |
| 烧杯加盖 | 层析液易挥发、有毒 |

**结果（从上到下）：胡萝卜素（橙黄）→ 叶黄素（黄）→ 叶绿素 a（蓝绿，最宽）→ 叶绿素 b（黄绿）**

**口诀：「胡黄 a b」，从上往下；跑最快的胡萝卜，最宽最粗叶绿 a。**

**结果异常分析：**
| 现象 | 原因 |
|---|---|
| 色素带颜色都很浅 | 研磨不充分（没加 SiO₂）；乙醇加太多；叶片太少；画线次数太少 |
| 叶绿素带很窄、很浅 | **没加 CaCO₃**，叶绿素被破坏；或用了**发黄的叶子** |
| 没有色素带 | 滤液细线**触到了层析液** |
| 色素带重叠 | 滤液细线画得太粗 |

### 2.4 光合作用探索历程（选择题考结论）

| 科学家 | 做了什么 | 结论 |
|---|---|---|
| 恩格尔曼 | 水绵 + **需氧细菌**，用极细光束照射；后用三棱镜分光 | **叶绿体是光合作用的场所**、**O₂ 由叶绿体释放**；**红光和蓝紫光区域**放氧多 |
| 希尔（1937） | **离体叶绿体**悬浮液加**铁盐（氧化剂）**，光照放出 O₂ | 离体叶绿体在光下可**分解水、放出 O₂**（希尔反应）；**不能说明 O₂ 中的 O 全部来自水** |
| 鲁宾和卡门（1941） | **同位素 ¹⁸O** 分别标记 H₂O 和 CO₂ | **光合作用释放的 O₂ 全部来自水** |
| 阿尔农（1954） | 光照下叶绿体合成 ATP | 叶绿体在光下合成 ATP，**总与水的光解相伴随** |
| 卡尔文 | **¹⁴C** 标记 CO₂，追踪小球藻 | 暗反应途径：**CO₂ → C₃ → (CH₂O)**（**卡尔文循环**） |

> ⚠ 注意：¹⁸O 是**稳定同位素**，没有放射性，是测**相对分子质量**；¹⁴C、³H、³²P、³⁵S 是**放射性同位素**。

### 2.5 光反应和暗反应（核心中的核心）

| | 光反应 | 暗反应（卡尔文循环） |
|---|---|---|
| 场所 | **类囊体薄膜** | **叶绿体基质** |
| 条件 | **光、色素、酶** | **酶**（不直接需要光，但需要光反应提供的 ATP 和 NADPH） |
| 物质变化 | ① **水的光解**：H₂O → **O₂** + H⁺ + e⁻，H⁺ 与 **NADP⁺** 结合生成 **NADPH**<br>② **ATP 的合成**：ADP + Pi → ATP | ① **CO₂ 的固定**：CO₂ + **C₅** → **2C₃**<br>② **C₃ 的还原**：C₃ —ATP、NADPH→ (CH₂O) + **C₅**（C₅ 再生） |
| 能量变化 | **光能 → ATP 和 NADPH 中活跃的化学能** | **活跃的化学能 → 有机物中稳定的化学能** |
| 联系 | 光反应为暗反应提供 **ATP 和 NADPH**；暗反应为光反应提供 **ADP、Pi 和 NADP⁺** | |

**口诀：**
- **光反应：「水光解，放氧气，造出 ATP 和 NADPH」**（在类囊体）。
- **暗反应：「一固定（CO₂+C₅→2C₃），二还原（C₃→糖+C₅），C₅ 循环再利用」**（在基质）。

**必背句：**
- **O₂ 来自水的光解**（不是来自 CO₂）。
- **ATP 和 NADPH 用于 C₃ 的还原**，**不用于 CO₂ 的固定**。
- 暗反应「不需要光」不等于「在黑暗中能一直进行」：停止光照后，暗反应**还能进行一小段时间**，ATP 和 NADPH 用完就停。
- 元素去向：CO₂ 中的 C：**CO₂ → C₃ → (CH₂O)**；H₂O 中的 O → **O₂**；CO₂ 中的 O → **(CH₂O) 和 H₂O**。

### 2.6 条件骤变时物质含量怎么变（江苏选择题、大题都考）

**方法（来源去路法）：** 一个物质的量 = 来源 − 去路。条件改变瞬间，看**谁的来源或去路先变**。

| 条件突变 | ATP、NADPH | C₃ | C₅ | (CH₂O) 合成 |
|---|---|---|---|---|
| **光照减弱/停止** | **↓**（光反应变弱，产生少了） | **↑**（C₃ 还原变慢，消耗少了；生成不变） | **↓**（再生少了；消耗不变） | ↓ |
| **光照增强** | ↑ | ↓ | ↑ | ↑ |
| **CO₂ 减少** | **↑**（C₃ 少了，用得少了） | **↓**（固定少了，生成少了） | **↑**（消耗少了） | ↓ |
| **CO₂ 增加** | ↓ | ↑ | ↓ | ↑ |

**口诀：「光减 C₃ 升，CO₂ 减 C₃ 降；C₅ 永远和 C₃ 反着走；ATP 跟着光走。」**

**例 2** 正常光照的植物，突然停止光照，短时间内叶绿体中 C₃ 和 C₅ 怎么变？
1. 停光 → 光反应停 → ATP、NADPH 减少。
2. C₃ 的去路是「被还原」，要 ATP 和 NADPH → 去路变小；C₃ 的来源是 CO₂ 固定，CO₂ 没变 → 来源不变 → **C₃ 增加**。
3. C₅ 的来源是 C₃ 还原后再生 → 来源变小；去路是固定 CO₂ → 不变 → **C₅ 减少**。

### 2.7 影响光合作用的因素（曲线题）

| 因素 | 怎么影响 | 应用 |
|---|---|---|
| **光照强度** | 影响**光反应**（ATP、NADPH 的生成） | 合理密植、间作套种、补光 |
| **CO₂ 浓度** | 影响**暗反应**（CO₂ 的固定） | 大棚施**农家肥**（微生物分解产生 CO₂）、**正其行，通其风** |
| **温度** | 影响**酶的活性** | 白天适当升温、**夜间适当降温**（减少呼吸消耗） |
| **水** | 缺水 → **气孔关闭 → CO₂ 吸收减少** | 合理灌溉 |
| **矿质元素** | **N**（酶、叶绿素、ATP、NADPH）、**Mg**（叶绿素）、**P**（ATP、NADPH、磷脂） | 合理施肥 |

**光照强度曲线上的三个关键点：**
- **A 点（光照为 0）**：只进行**呼吸作用**，纵坐标 = **呼吸速率**。
- **B 点（光补偿点）**：**光合速率 = 呼吸速率**，净光合 = 0。
- **C 点（光饱和点）**：再增加光照，光合不再增加；此后的**限制因素**是 **CO₂ 浓度、温度**等（内因：色素和酶的量）。
- 达到饱和点前，限制因素是**光照强度**（横坐标因素）。

**补偿点、饱和点怎么移（必会）：**
| 条件变化 | 光补偿点 | 光饱和点 |
|---|---|---|
| **CO₂ 浓度适当增加** | **左移** | **右移** |
| **缺 Mg（叶绿素少）** | **右移** | **左移** |
| 温度从**光合最适**调到**呼吸最适**（如 25℃→30℃） | **右移** | **左移**（最高点也下降） |
| **阴生植物** vs 阳生植物 | 阴生植物**更低（偏左）** | 阴生植物**更低（偏左）** |

> 记法：**对光合有利 → 补偿点左移、饱和点右移；对光合不利 → 反过来。**

**夏季「光合午休」：** 中午温度高、蒸腾强 → **气孔部分关闭** → **CO₂ 吸收减少** → **暗反应减弱** → 光合速率下降（此时 C₃ ↓、C₅ ↑）。

## 第三部分 光合与呼吸的综合（压轴，必须吃透）

### 3.1 三个「速率」——看关键词就知道是哪个

**总光合速率 = 净光合速率 + 呼吸速率**

| 速率 | 题目里的说法（关键词） |
|---|---|
| **总（真正）光合速率** | 叶绿体**产生/制造/生成** O₂、**固定/同化** CO₂、**制造/合成**有机物 |
| **净（表观）光合速率** | 植物（叶片）**释放** O₂、**从外界吸收** CO₂、有机物**积累量**、**增重**；**光照下测得**的气体变化 |
| **呼吸速率** | **黑暗中**测得的 O₂ 吸收量、CO₂ 释放量、有机物减少量 |

**植物能不能生长，看净光合是否大于 0**（一昼夜：积累 = 白天净光合总量 − 夜间呼吸总量）。

### 3.2 不同光照下，叶肉细胞和外界的气体交换（图示题）

| 光照情况 | 关系 | 线粒体需要的 O₂ 来自 | 叶绿体需要的 CO₂ 来自 | 和外界交换 |
|---|---|---|---|---|
| 黑暗 | 只呼吸 | 外界 | （不进行光合） | 吸 O₂、放 CO₂ |
| 弱光（补偿点前） | 光合 **<** 呼吸 | 叶绿体 + 外界 | 全部来自线粒体 | 吸 O₂、放 CO₂ |
| 光补偿点 | 光合 **=** 呼吸 | 全部来自叶绿体 | 全部来自线粒体 | **不交换** |
| 较强光 | 光合 **>** 呼吸 | 全部来自叶绿体 | 线粒体 + 外界 | 吸 CO₂、放 O₂ |

> ⚠ 易错：**整株植物**的补偿点 ≠ **叶肉细胞**的补偿点。整株植物光合 = 呼吸时，**叶肉细胞的光合 > 叶肉细胞的呼吸**（因为根、茎等不进行光合的细胞也在呼吸）。

### 3.3 密闭玻璃罩一昼夜 CO₂ 浓度曲线

- CO₂ 浓度**上升** → 呼吸 > 光合；**下降** → 光合 > 呼吸。
- **曲线的拐点（最高点、最低点）**：**光合 = 呼吸**。
- **CO₂ 浓度最低点（傍晚，约 18 时）**：一天中**有机物积累最多**。
- **24 时 CO₂ 浓度低于 0 时** → 一昼夜**有机物增加**，植物生长；高于 → 减少。

（开放环境测 CO₂ 吸收速率的曲线，**和横轴围成的面积**：横轴上方 = 积累，横轴下方 = 消耗。）

### 3.4 经典计算

**例 3（气体换算）** 黑暗中，某植物每小时释放 CO₂ 20 mg；适宜光照下，每小时从外界吸收 CO₂ 44 mg。求：①总光合速率（以 CO₂ 计）；②每小时实际制造葡萄糖多少 mg。

1. 「黑暗中释放」是**呼吸速率**：20 mg/h；「从外界吸收」是**净光合速率**：44 mg/h。
2. 总光合 = 净光合 + 呼吸，代入：44 + 20 = **64 mg CO₂/h**。
3. 由 6CO₂ → 1 C₆H₁₂O₆：6×44 = 264 g CO₂ 对应 180 g 葡萄糖。
   葡萄糖 = 总 CO₂ × 180 ÷ 264，代入：64 × 180 ÷ 264 ≈ **43.6 mg**。

**例 4（叶片增减重，必考套路）** 叶片在 25℃ 暗处理 1 h，质量减少 a；随后光照 1 h，质量比**暗处理前**增加 b。求呼吸速率、净光合速率、总光合速率。

1. 暗处理 1 h 只呼吸：**呼吸速率 = a**。
2. 光照这 1 h：从「暗处理后」（已经少了 a）变成「比暗处理前多 b」，共增加 a + b → **净光合 = a + b**。
3. 总光合 = 净光合 + 呼吸，代入：(a + b) + a = **2a + b**。

**例 5（一昼夜积累）** 某植物光照下净光合（以 CO₂ 吸收计）为 44 mg/h，黑暗中呼吸为 20 mg/h。每天光照 12 h、黑暗 12 h，能否生长？
1. 一昼夜积累（以 CO₂ 计）= 净光合 × 光照时长 − 呼吸 × 黑暗时长。
2. 代入：44 × 12 − 20 × 12 = 528 − 240 = **288 mg > 0**，**能生长**。

### 3.5 光合与呼吸的联系

| | 光合作用 | 有氧呼吸 |
|---|---|---|
| 场所 | 叶绿体 | 细胞质基质 + 线粒体 |
| 物质 | CO₂ + H₂O → 有机物 + O₂ | 有机物 + O₂ → CO₂ + H₂O |
| 能量 | 光能 → 化学能（**储存**能量） | 化学能 → ATP + 热能（**释放**能量） |
| [H] | **NADPH**，用于还原 C₃ | **NADH**，与 O₂ 结合生成水 |
| ATP 去向 | 光反应的 ATP **只用于暗反应**（C₃ 的还原） | 呼吸产生的 ATP 用于**各项生命活动** |
| 进行条件 | 只在**有光**时、**含叶绿体的细胞** | **所有活细胞时时刻刻**都在进行 |

> ⚠ 易错：「植物生命活动的能量直接来自光合作用」✗。**光合产生的 ATP 只给暗反应**，其他生命活动用的 ATP 来自**细胞呼吸**。

## 第四部分 加深篇（把「为什么」讲透，江苏卷信息题常从这里出）

> 这一部分是课本「拓展/科学·技术·社会」和江苏卷材料题经常出现的内容。先把第一～三部分背熟，再看这里。

### 4.1 有氧呼吸第三阶段到底怎么产生大量 ATP

前面只背了「[H] + O₂ → H₂O，释放大量能量」。具体过程是：

1. **NADH 把电子交给线粒体内膜上的一串蛋白质**（叫**电子传递链**），电子一个接一个往下传，**最后交给 O₂**，O₂ 和 H⁺ 结合生成 **H₂O**。
   → 所以 **O₂ 是最终的电子受体**。没有 O₂，电子传不下去，第三阶段停，第二阶段也跟着停。
2. 电子传递时放出的能量，被用来**把 H⁺ 从线粒体基质泵到膜间隙**（内膜和外膜之间）。
   → 结果：**膜间隙 H⁺ 浓度高，基质 H⁺ 浓度低**，形成 H⁺ 浓度梯度。
3. H⁺ 顺着浓度梯度，**通过内膜上的 ATP 合酶流回基质**，ATP 合酶借这股「水流」把 **ADP + Pi 合成 ATP**。

> 大白话：水泵把水抽到高处（泵 H⁺），水往下流时冲动水车（ATP 合酶）发电（合成 ATP）。
> **必背：ATP 合酶既是 H⁺ 的通道蛋白，又能催化 ATP 合成。**
> 常考：某药物使内膜对 H⁺ 的通透性增大（H⁺ 不经 ATP 合酶直接漏回去）→ **ATP 合成减少，能量更多以热能散失**，O₂ 消耗反而可能增加。

### 4.2 光反应到底怎么产生 O₂、NADPH 和 ATP

类囊体薄膜上有两个吸光的「色素–蛋白质复合体」：**光系统Ⅱ（PSⅡ）**和**光系统Ⅰ（PSⅠ）**。

1. **PSⅡ 吸收光能，把水分解**：H₂O → **O₂ + H⁺ + e⁻**。O₂ 和 H⁺ 留在**类囊体腔**内（O₂ 再扩散出去）。
2. 电子经**电子传递链**从 PSⅡ 传到 PSⅠ；传递过程中又**把基质中的 H⁺ 泵进类囊体腔**。
3. **PSⅠ 再吸收光能**，把电子「推」得更高，最后交给 **NADP⁺**，NADP⁺ + H⁺ + 2e⁻ → **NADPH**（在**基质一侧**生成）。
4. 结果：**类囊体腔 H⁺ 浓度高、基质 H⁺ 浓度低**。H⁺ 顺梯度**经 ATP 合酶从类囊体腔流到基质**，合成 **ATP**（ATP 也在**基质一侧**生成）。
   → 所以 ATP 和 NADPH 一生成就在基质里，正好给暗反应用。

**线粒体和叶绿体对比（江苏卷爱考）：**
| | 线粒体内膜 | 类囊体薄膜 |
|---|---|---|
| 电子来源 | NADH | **水** |
| 最终电子受体 | **O₂** | **NADP⁺** |
| H⁺ 被泵到 | 膜间隙 | **类囊体腔** |
| ATP 合成在 | 基质一侧 | 叶绿体基质一侧 |
| 能量来源 | 有机物中的化学能 | **光能** |

### 4.3 呼吸底物不一定是葡萄糖：呼吸熵

**呼吸熵（RQ）= 释放的 CO₂ 量 ÷ 吸收的 O₂ 量**（有氧呼吸时）

| 底物 | RQ | 为什么 |
|---|---|---|
| 糖类 | **= 1** | 6O₂ 对 6CO₂ |
| 脂肪 | **< 1（约 0.7）** | 脂肪**含 H 多、含 O 少**，氧化时要消耗更多 O₂ |
| 蛋白质 | 约 0.8 | |

**应用：**
- **油料种子（花生、油菜）萌发时 RQ < 1**；同质量的脂肪比糖类储能多、耗氧多 → **油料种子播种要浅一些**（土壤表层 O₂ 多）。
- 若测得 RQ > 1（以葡萄糖为底物），说明同时有**酒精发酵**。
- ⚠ 所以 1.5 节「CO₂ = O₂ 只进行有氧呼吸」的结论，**前提是底物为葡萄糖**。

### 4.4 O₂ 浓度对细胞呼吸的曲线（细讲）

以某植物器官为例，横轴 O₂ 浓度，纵轴 CO₂ 释放量：
- **O₂ = 0**：只进行无氧呼吸，CO₂ 全来自酒精发酵。
- O₂ 增加：**无氧呼吸被抑制而减弱**，**有氧呼吸增强**；总 CO₂ 先下降后上升。
- **总 CO₂ 释放量最低点（如约 5%）**：此时**有机物消耗最少**，是储存果蔬的最佳 O₂ 浓度。
  ⚠ 这一点**不是无氧呼吸为零的点**，此时两种呼吸都在进行。
- **无氧呼吸消失点**：CO₂ 释放量曲线与 O₂ 吸收量曲线**重合的起点**；此后只进行有氧呼吸。
- O₂ 再增加，有氧呼吸不再增强 → 受**酶的数量、温度**等限制。

### 4.5 温度和 CO₂ 的曲线（细讲）

**温度曲线**：
- 总光合和呼吸都**先升后降**（酶）。一般**光合作用的最适温度低于呼吸作用的最适温度**（光合相关酶对高温更敏感）。
- **最适合植物生长的温度 = 净光合速率最大时的温度**，不一定是总光合最大时的温度。
- 当总光合 = 呼吸时，净光合 = 0；温度再高，植物不能积累有机物。

**CO₂ 浓度曲线**：
- **CO₂ 补偿点**：光合 = 呼吸时的 CO₂ 浓度；**CO₂ 饱和点**：光合不再随 CO₂ 增加。
- 「光照增强」对 CO₂ 曲线的影响：CO₂ 补偿点**左移**、饱和点**右移**（同样是「有利 → 补偿左、饱和右」）。
- **C₄ 植物的 CO₂ 补偿点比 C₃ 植物低**（见 4.7）。

### 4.6 光呼吸（材料题高频）

- 催化 CO₂ + C₅ 的酶叫 **Rubisco**（核酮糖-1,5-二磷酸羧化酶/加氧酶），它**既能和 CO₂ 结合，也能和 O₂ 结合**。
- 在**光下、O₂ 浓度高而 CO₂ 浓度低**时（如晴天中午气孔关闭），Rubisco 让 **C₅ 与 O₂ 结合**，经过叶绿体、过氧化物酶体、线粒体的一系列反应，**消耗 ATP 和 NADPH，最后释放 CO₂**。这就是**光呼吸**。
- **坏处**：让一部分 C₅ 没去固定 CO₂，还**放出已固定的碳**，**降低光合效率**。
- **好处**：强光下**消耗过剩的 ATP 和 NADPH**，避免它们积累对叶绿体造成伤害（**光保护**）；还能回收部分碳。
- **光呼吸 vs 细胞呼吸**：光呼吸**只在光下**、不产生 ATP 反而消耗 ATP；细胞呼吸**有光无光都进行**、产生 ATP。
- 提高 CO₂ 浓度（如大棚）能**抑制光呼吸**，这也是增产的原因之一。

### 4.7 C₄ 植物和 CAM 植物（了解原理，会读图）

> 详细版（途径逐步讲解、区分实验、曲线、4 道大题）见 [01拓展-C3C4CAM植物与大题拓展](01拓展-C3C4CAM植物与大题拓展.md)。

| | C₃ 植物 | C₄ 植物 | CAM 植物 |
|---|---|---|---|
| 举例 | 水稻、小麦、大豆 | **玉米、甘蔗、高粱** | **仙人掌、菠萝、景天** |
| CO₂ 最先固定成 | C₃ | **C₄（草酰乙酸，再变苹果酸等）** | **C₄（苹果酸）** |
| 怎么分开 | — | **空间分开**：**叶肉细胞**用 **PEP 羧化酶**固定 CO₂ 成 C₄ → 运到**维管束鞘细胞**放出 CO₂ → 进行卡尔文循环 | **时间分开**：**夜间气孔开**，固定 CO₂ 成苹果酸储存在**液泡**（夜间细胞液 pH 下降）；**白天气孔关**，苹果酸放出 CO₂ 进行卡尔文循环 |
| 优势 | — | **PEP 羧化酶与 CO₂ 亲和力很强**，像「CO₂ 泵」，在**低 CO₂、高温强光**下仍能高效光合；**CO₂ 补偿点低**；光呼吸弱 | 白天关气孔**减少水分散失**，适应**干旱** |
| 结构特点 | — | 维管束鞘细胞外有叶肉细胞环绕（**花环型结构**）；维管束鞘细胞叶绿体**没有（或少有）基粒** | 多为肉质植物 |

> 判断题常考：**C₄ 植物最终合成糖类仍然靠卡尔文循环（C₃ 途径）**，只是多了一个「先浓缩 CO₂」的步骤。

### 4.8 测定光合和呼吸的四种实验方法

**方法一：液滴移动法（装置题，江苏常考）**

装置：密闭小瓶 + 植物 + 小烧杯（放某种溶液）+ 带红色液滴的刻度管。液滴移动反映**瓶内气体体积变化**。

| 测什么 | 条件 | 小烧杯里放 | 液滴怎么动、代表什么 |
|---|---|---|---|
| **呼吸速率** | **黑暗（遮光）** | **NaOH 溶液**（吸收 CO₂） | 植物吸 O₂、放出的 CO₂ 被吸收 → 气体减少，液滴**向瓶的方向移动**，距离 = **O₂ 消耗量** |
| **净光合速率** | **光照** | **CO₂ 缓冲液（NaHCO₃）**（保持 CO₂ 浓度不变） | 植物放 O₂ → 气体增多，液滴**向远离瓶的方向移动**，距离 = **O₂ 释放量（净光合）** |
| 判断呼吸方式（种子） | 黑暗 | 一组 NaOH，一组**清水** | NaOH 组：O₂ 消耗量；清水组：CO₂ 释放量 − O₂ 吸收量。**清水组液滴不动 → 只有氧呼吸；外移 → 有无氧呼吸（酒精发酵）** |

- **对照组（校正）**：放**死的植物（或煮熟的种子）**，其余相同，排除温度、气压等**物理因素**引起的误差。实际值 = 实验组读数 − 对照组读数。
- 总光合 = 光照下的净光合 + 黑暗下的呼吸（两套装置）。

**方法二：叶圆片上浮法**
1. 用打孔器打出叶圆片，**抽气使叶圆片细胞间隙的气体排出**，叶圆片沉到水底。
2. 放入 **NaHCO₃ 溶液**（**提供 CO₂**）中，给光照。
3. 光合产生 O₂ 积累在细胞间隙 → 叶圆片**上浮**。
4. 因变量：**相同时间内上浮的叶圆片数量**，或**叶圆片全部上浮所用时间**（越短，净光合越强）。
5. ⚠ NaHCO₃ 浓度过高 → 叶片细胞**渗透失水**，光合反而下降。

**方法三：半叶法（测总光合）**
1. 选对称叶片，**一半遮光、一半照光**（并处理叶柄阻止有机物运出）。
2. 一段时间后，两半各取相同面积 S，烘干称重：遮光部分 A，照光部分 B。
3. 两半起点相同；遮光部分只呼吸（减少），照光部分净光合（增加）。
   **总光合速率 = (B − A) ÷ (S × t)**。

**方法四：黑白瓶法（水生植物/浮游植物）**
- 白瓶（透光）测 **净光合**，黑瓶（不透光）测 **呼吸**，初始瓶测起始溶氧。
- 呼吸量 = 初始瓶溶氧 − 黑瓶溶氧；净光合 = 白瓶溶氧 − 初始瓶溶氧；**总光合 = 白瓶溶氧 − 黑瓶溶氧**。

### 4.9 加深例题

**例 6（液滴装置）** 某装置内放绿色植物和 CO₂ 缓冲液，光照 1 h 液滴外移 6 格；同样装置遮光、换成 NaOH 溶液，1 h 液滴内移 2 格；放死植物的对照组 1 h 外移 1 格。每格代表 1 mL O₂。求总光合速率。
1. 先校正：死植物组外移 1 格，说明物理因素让气体「多了」1 mL。
2. 净光合 = 实验读数 − 对照读数，代入：6 − 1 = **5 mL/h**。
3. 呼吸：内移 2 格，物理因素又让它往外推了 1 格，真实内移 = 2 + 1 = **3 mL/h**。
4. 总光合 = 净光合 + 呼吸，代入：5 + 3 = **8 mL O₂/h**。
> 校正思路：物理误差在两组里方向相同，都要「扣掉」。

**例 7（黑白瓶）** 初始瓶溶氧 10 mg/L，24 h 后白瓶 14 mg/L，黑瓶 7 mg/L。
- 呼吸 = 初始 − 黑瓶，代入：10 − 7 = **3 mg/L**；
- 净光合 = 白瓶 − 初始，代入：14 − 10 = **4 mg/L**；
- 总光合 = 白瓶 − 黑瓶，代入：14 − 7 = **7 mg/L**（= 4 + 3，验算一致）。

**例 8（光呼吸材料）** 夏季晴天中午，某 C₃ 植物光合速率下降，而玉米下降不明显。用所学知识解释。
答题要点：中午气孔部分关闭，叶肉细胞间 **CO₂ 浓度降低、O₂ 浓度相对升高**，C₃ 植物 **Rubisco 催化 C₅ 与 O₂ 结合，光呼吸增强**，**暗反应 CO₂ 固定减少**，光合速率下降；玉米是 C₄ 植物，**PEP 羧化酶与 CO₂ 亲和力强**，能利用低浓度 CO₂，并把 CO₂ **浓缩到维管束鞘细胞**，**光呼吸弱**，所以下降不明显。

**例 9（呼吸熵）** 花生种子萌发初期，测得 CO₂ 释放量 0.7 mol，O₂ 吸收量 1.0 mol（不考虑无氧呼吸）。说明什么？
- RQ = CO₂ ÷ O₂，代入：0.7 ÷ 1.0 = **0.7 < 1**，说明主要以**脂肪**为呼吸底物（脂肪含 H 多、O 少，耗氧多）。

## 第五部分 江苏卷答题关键词（直接背）

1. **问「为什么光照增强光合速率增大」**：光照增强，光反应产生的 **ATP 和 NADPH 增多**，**C₃ 的还原加快**。
2. **问「为什么 CO₂ 增加光合增强」**：**CO₂ 的固定加快，生成的 C₃ 增多**，暗反应加快。
3. **问「中午光合下降」**：温度高、**蒸腾作用过强**，**气孔部分关闭**，**CO₂ 吸收减少**，暗反应减弱。
4. **问「缺 Mg 为什么光合下降」**：Mg 是**叶绿素的组成元素**，叶绿素合成减少，**吸收、传递、转化光能减少**，光反应减弱。
5. **问「夜间降温为什么增产」**：降低**呼吸酶活性**，**呼吸作用减弱，有机物消耗减少**，积累增多。
6. **问「类囊体结构的意义」**：类囊体堆叠成基粒，**增大了膜面积**，为**色素和光反应的酶**提供了附着位点。
7. **问「线粒体内膜向内折叠的意义」**：**增大内膜面积**，为**有氧呼吸第三阶段的酶**提供附着位点。
8. **问「为什么要设置黑暗组/测呼吸」**：用于测定**呼吸速率**，**总光合 = 净光合 + 呼吸**。
9. **实验设计：** 自变量（如光照强度——用**灯与装置的距离**或**不同功率的灯**控制）；因变量（O₂ 释放速率、CO₂ 吸收速率、**叶圆片上浮时间**、有机物积累量）；无关变量（温度、CO₂ 浓度、叶片大小等）要**相同且适宜**。
