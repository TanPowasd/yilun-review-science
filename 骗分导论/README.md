# 骗分导论

> 正规复习之外的另一条线：**会做的按正规方法做，不会做的别空着**。选择填空只看答案，所以特殊值、代选项、估算、二级结论都合法；大题不会做也能蹭步骤分。
>
> 每一招都写清楚什么时候能用、怎么用、什么时候会翻车，例题都给「骗分做法」和「正规做法」两种对照，题目和答案集中放在文末。
